## Corrections and findings

- `Traversable`: the extension `Traverse` is declared on `K<T, A>`, but the extension `TraverseM` is declared on the function (`Func<A, K<M, B>>.TraverseM(K<T, A>)`). A generic function over `K<T, A>` calls the trait members `T.Traverse(f, ta)` and `T.TraverseM(f, ta)` for one spelling. The `Seq<A>` instance members `Traverse`/`TraverseM` are the concrete forms.
- `Applicative`: there is no `Apply(this K<F, Func<A, B>>, K<F, A>)` extension in `ApplicativeExtensions`; the function-in-context form is the trait call `F.Apply(mf, ma)`. The tuple `Apply` extension exists for arity two to nine over `K<F, A>` operands.
- `Foldable`: `Fold`, `FoldBack`, `Exists`, `ForAll`, `At` are extension-block members on `K<T, A>` (the decompile shows them nested under `FoldableExtensions`), and they resolve on a generic `K<T, int>` with `T : Foldable<T>`.
- `Prelude.tail<A>(IO<A>)` marks a tail call on `IO`, and `Prelude.tailIO<M, A>(K<M, A>) where M : MonadUnliftIO<M>` is the transformer-level marker. The doc names `tail`.
- `Deriving.MonadIO<Counter, StateT<int, IO>>` does not compile: it requires `Subtype : MonadIO<Subtype>` and `StateT<S, M>` implements only `Maybe.MonadIO`. `Deriving.Monad` plus `Deriving.Stateful` is the smallest derivation for a `StateT` wrapper. `Deriving.Alternative` and its `Empty` requirement were not compiled.
- Analyzer: a witness class with only static trait implementations fails CA1812 as `sealed`; `abstract` satisfies it and static abstract interface members still resolve. A tuple local read through one member fails IDE0042, so the samples deconstruct (`(_, int resetState) = ...`). A captured lambda must not be `static`, and `Try.lift(static () => ...)` is required when nothing is captured (MA0217). `Validation<Error, string>.Success` is a nested type, not a factory, so the check uses `Match`.
- `Error` does not convert to `K<Validation<Error>, int>` at a generic call site; a typed `Validation<Error, int>` local carries the implicit lift.
- The tuple `Apply` on `ValidationT<Error, IO, A>` runs both effects and accumulates both errors, matching `Validation`.
- `ReaderT.liftIO` with `M = OptionT<IO>` compiles under the `Monad<M>` constraint and reaches the inner `IO` through `OptionT`'s `Maybe.MonadIO`.
- `Trampoline<int>` summing to 100000 overflows under `CheckForOverflowUnderflow`; the sample uses `Trampoline<long>`.
- API document row `FinT.Succ(A) / FinT.Fail(Error)`: both exist as `FinT.Succ<M, A>(A)` and `FinT.Fail<M, A>(Error)` module functions (decompile of `LanguageExt.FinT`); not compiled here.
