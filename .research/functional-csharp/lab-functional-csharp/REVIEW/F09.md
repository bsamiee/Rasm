## Findings

1. **Location** line 45.
   **Claim** "This equation is the functor composition law that makes `Map` trustworthy."
   **Evidence** Buonanno chapter 5 line 45 states "Two laws make `Map` trustworthy" and lists identity as the
   second. `12-applicatives-and-laws.md` line 107 repeats both laws and says `FunctorLaw<F>.validate` "checks both
   laws". One law alone does not make `Map` trustworthy, so the sentence asserts a claim neither book nor the
   corpus supports.
   **Correction** replace the sentence with: `This equation is the functor composition law.`

2. **Location** line 127, last sentence.
   **Claim** "Workflow functions are passed to `Map`, `Filter`, `Bind`, or `Iter`, and the result type controls
   whether the value reaches the next step."
   **Evidence** `Fin<A>` has no `Filter` and no `Where`: `sigs/Fin_1.txt` and `sigs/FinExtensions.txt` contain
   neither, and the F09 notes record the same from the decompile. The preceding sentence now says the operators
   "on `Option` and `Fin`" provide the glue, so the list attributes `Filter` to `Fin`. The section's own code
   glues the `bool` step with `guard`, which takes the flag, not the function.
   **Correction** replace the sentence with: `Workflow functions are passed to `Map`, `Filter`, `Bind`, or
   `Iter`, and a `bool` step reaches `Fin` through `guard`. The result type controls whether the value reaches
   the next step.`

3. **Location** line 213, end of "Compose the End-to-End Flow".
   **Claim** "`Save` and `Wire` run only when both succeed, and each effect is one visible step of the query."
   **Evidence** The book's `Book` was `void` and performed its effects when called. `Book` now returns
   `IO<Unit>`, a description that performs nothing until it runs, and the file never names the operation that
   runs it. `IO<A>.RunSafe() : Fin<A>` exists (`sigs/IOExtensions.txt` line 43) and the lab exits through
   `transfers.Book(transfer).RunSafe()` in `Samples.cs`. The brief requires the boundary rule once per file where
   relevant, and this is the file's only effect boundary.
   **Correction** append one sentence: `The host runs `Book` with `RunSafe`, which returns `Fin<Unit>` and carries
   the typed error out of the effect.`

4. **Location** line 28, and the `compose` call at line 32.
   **Claim** "The Prelude function `compose` builds the same function as one reusable value, and its arguments
   read in execution order."
   **Evidence** The block spells `compose<Person, string, string>(...)` with explicit type arguments. The F09
   notes record that inference cannot fix `T1` from a method group, so the bare `compose(f, g)` a reader copies
   fails with CS0411. The file is self-contained and states the requirement nowhere.
   **Correction** append one clause to the sentence: `..., and its arguments read in execution order. `compose`
   needs explicit type arguments when its arguments are method groups.`
