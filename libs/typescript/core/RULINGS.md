## [02]-[SHAPE]

- Instrument-to-`Metric` materialization homes at the `Convention` owner, never the consumer sites — one mount reads each row's wire form, value width, bucket ladder, UCUM code, and description into the live handle, so a signal site names an instrument and receives it. Per-site constructor picks re-spell the boundary vector at every consumer, drop the unit carrier the exported descriptor reads, and drift from the contract the row already declares.
- Closed vocabularies publish their roster as an ordered tuple beside the lookup table, so a consuming schema spreads it into the non-empty literal overload and decodes to the closed union. Free-string columns standing beside a table that already fixes the vocabulary admit a unit, kind, or level no mount can honour, and a values walk over that table types as an unordered array that forfeits the non-empty overload outright, dropping the seam meant to close the set back to a free string.
- Instrument kind names the EXPORTED wire form rather than statistical intent — a monotonic sum, a non-monotonic sum, a level, a word census, and a distribution each take their own case, so the tail projection, the residence table, and the mount all read one column. Levels maintained by increment and release wearing a level row export a sum no level query answers and route a columnar read to the wrong table.
- Dimensionless `1` names a ratio and nothing else, because a suffixing receiver renders a `1`-coded level as `<name>_ratio` — a level counting deliverables, renders, hits, or drain positions takes the annotation code naming what it counts, so the projected series states the measured noun and the panel, the objective, and the alert rule all read one spelling. Minting a count dimensionless renames it at the store, where no consumer can tell a queue depth from a fraction.
- Bucket edges freeze at the mint and read no tunable policy row — a collected distribution point cannot be re-bucketed, so a cost, budget, or ceiling bump moves the objective naming the series and leaves the ladder standing; a ladder interleaving policy targets re-buckets a live series the first time an operator tunes one.
- Bucket ladders generate from scalars and transcribe only what an external contract fixes — an enumerated vector at a row hides the rung law the next edit must preserve, and `count` counts the finite edges alone so the projected edge set and the minted buckets are provably one array a bucket-bound query can name.
- Suffixing is a render-target property `Convention.translated` projects, never a name a `_metric` row bakes — receivers append the unit word and type tail at ingest, so a mint name and a store's series are two facts the query fold bridges through the strategy its target names. Baking a tail breaks Tier-0's dotted grammar and still misses every store translating differently; re-deriving one at a consumer forks the correspondence the unit and kind columns carry.
- One `Query` owner renders every backend and the target is a parameter, never a fork — expression data stays dialect-free, operator rows carry one column per target, and engine grammar is a closed roster whose residence schema arrives as caller data. Second query languages, second board owners, and raw-dialect tiles each re-import the forked discipline the two SLI projections delete, and a target-specific breach expression is that fork wearing one owner's name.
- `Query.Target` closes over the METRIC-SERIES backends alone, so a span-selection dialect earns no arm — every leaf keys a metric name against a series name, and folding a span language into that family forges a selector on whichever side lacks the other's shape. Trace evidence compiles as a residence panel over the wide-event relations a columnar plane already relates, so the trace backend's own board reach is its store row's declared degradation.
- Instrument rows carry their own fan as a column, so the metric-plane roster a governor reads generates from the instrument table and never from the attribute census — that census carries identifier-grade keys for span and log use, so folding it whole admits every one of them and leaves the cardinality ceiling as the sole guard, pricing a burst as silently dropped series rather than a refused dimension; folding a governor's own mounted rows instead strips every plane it does not mount.
- Panels carry their own datasource key and the compile leg binds from it — a board mixing a metrics-store tile with a columnar-residence tile answers two backends, so deriving the key from the panel tag binds every table to whichever backend that tag defaulted to and empties a residence tile with no error anywhere.

## [03]-[COLLAPSE]

- Columns deriving wholly from a column their row already carries collapse into that derivation, and a guard proving the two equal proves the table earns no seat — a derived table demands one edit and one re-proof per row while the derivation carries the next row for free, and membership alone survives as a roster where order, iteration, or non-emptiness is the fact a consumer spends.
- `FaultClass`, `Budget`, and `Degrade` stay three row families under the one fault module — a shared declaration-time table generator is assembly machinery each family reuses, never a merge; folding them into one parameterized owner erases the class/retry/degrade policy split and mints a god-vocabulary, denser on paper and weaker at every policy seam.
- `Degrade` and `Availability` stay two owners — `Degrade` compiles local connection-silence policy into probe cadence, `Availability` lands the peer-minted degradation snapshot the serving gate types against; folding them writes a local liveness policy into peer-minted wire evidence and breaks the single-writer law the snapshot decodes under.
