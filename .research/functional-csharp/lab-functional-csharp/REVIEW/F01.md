2. **Location** line 178.
   **Claim** "`K<F, A>` carries the type constructor `F` as a type parameter. The traits `Functor<F>`,

   **Evidence** Three defects in added prose. (a) `F` is the witness, not the type constructor: the
   decompiled `K<in F, A>` documents `F` as "Trait type" and the remarks read "`K<F, A>` should be

   a witness". `As()` is spelled `.As()` everywhere else in the corpus, and file 23 says "restores the
   concrete type at the concrete edge".
   **Correction** "`K<F, A>` carries the witness `F` for the type constructor and the element type `A`.
   The traits `Functor<F>`, `Applicative<F>`, and `Monad<M>` state what a witness supports, so one
   function serves every type with a witness. `.As()` restores the concrete type at the concrete edge."

4. **Location** "### Recursion", between line 133's first and second sentences.
   **Claim** "Recursion replaces some mutation-driven loops with a function that calls itself using new
   argument values. Each call receives a new set of argument values rather than mutating the previous
   call's values."
   **Evidence** Painter chapter 1 lines 86 to 91 place a three-item list between those two sentences.
   The file drops it. The list is the section's only statement of what a recursive function requires,
   it is still true, and the corpus has no other owner for it (`17-indefinite-loops.md` owns the
   stack-safe operators, not the shape of a recursive function). Book prose dropped without cause.
   **Correction** Restore the book list between the two sentences:
   "Recursion replaces some mutation-driven loops with a function that calls itself using new argument
   values. A recursive function needs:

   1. an end condition that returns the final value;
   2. a recursive path that calls the same function with values closer to that condition;
   3. a returned value on every path.

   Each call receives a new set of argument values rather than mutating the previous call's values.
   Recursion can replace constructs such as `while` and `foreach`, but it requires caution in C#
   because a direct recursive formulation can have performance problems."
   The file is 284 lines, so this restoration and item 3 keep it under 300.
