# [RASM_APPUI_RULINGS]

`Rasm.AppUi` rulings settle package-scoped decisions.

## [01]-[PACKAGES]

- A transitive assembly a fence composes by member is admitted as a direct package, never consumed off the floor — `Mapsui.Nts` (basemap `Apply` binds `EditManager`/`EditMode` by name) and managed `HarfBuzzSharp` (typography tag-mint constructs `Feature`/`Tag`) each carry the full touch-point set: central `Directory.Packages.props` row, csproj `PackageReference`, README registry row, folder `.api/` catalog; a member-composing fence over a transitive-only assembly leaves the version pin, the catalog rail, and the registry claim all unowned. `--key` refusal on the assay rail is a top-level-source fact, never a decompile blocker — the managed DLL in the NuGet cache is the standing rail.

## [02]-[SHAPE]

- Durable counterparts to an evidence fold are SOURCES, never second folds — `EvidenceSource` hands back the same `ReceiptEnvelope` values live or resident, so the correlation join and the billing accrual each stay one implementation; the recurring move writes a store-side query returning pre-aggregated rows, re-deriving the accrual at a second site, and re-litigation opens only if the durable plane stops carrying whole envelopes.
- Every device-resident cache carries a BYTE ceiling and a least-recently-touched release, per plane class and per backend — geometry pages at `Render/meshlets` `ResidencyBudget`, texture planes at `Render/shading` `ShaderAssetCache`; a handle count is not a budget, because one 16k plane outweighs a thousand masks. Each resolution stamps a generation every plane it touches carries, and eviction never releases a cell at or above the live generation, so a budgeted cache cannot free a handle the current draw holds; the recurring move grows a `ConcurrentDictionary` of native handles until the device refuses, and re-litigation opens only if a single owner takes both plane classes.
- Raster shading READS a resolved `EnvironmentLight`; it never integrates one. Prefilter products — the SH irradiance run, GGX roughness ladder, split-sum LUT, and stored equirect — cross as data and blobs, and the roughness-to-level correspondence crosses as the ladder itself rather than its formula, so the level a raster shade picks and the level the prefilter wrote agree by construction; the recurring move re-derives an SH reconstruction or a level formula on the Render side to save a uniform, and re-litigation opens only if a backend cannot bind the ladder as a level set.
- A value arriving both from a local computation and from a store wire has ONE construction site — the local leg builds the wire shape and decodes through the same gate the store's answers take, so a locally built result cannot carry an anchor the decode would refuse and the two legs cannot drift; instantiated at `Document/search#SOURCE_COVERAGE`, binding every consumed-wire seam.
- A union whose roster a foreign backend closes carries no open or arbitrary arm — the backend's silent-drop path makes such an arm a no-op wearing a capability's name; instantiated at `Document/export#PDF_POLICY` (the three-key Skia annotation roster), governing every host-key vocabulary.
- A draft-edited immutable record is TWO type parameters, never one — the mutable notifying draft the property grid writes in place and the record its commit rebuilds; conflating them on one parameter makes "persist the rebuilt value, never the draft" unenforceable at the seam, and the grid packages carry no immutable-record facility, so the draft is mandatory, not a style choice.
- A host control's presented editor receives its write channel BOUND, never the raw descriptor — the framework's own factory write path carries the command mint, the veto edge, and the undo enqueue, and a direct descriptor write bypasses all three at once while type-checking clean.
- Receipt sealing is double-count-proof by construction — a running-total scan feeding a per-delta receipt seals the per-delta cell, never the cumulative one, and two receipt producers on one user action seal DISTINCT outcome cases wherever the evidence fan routes on outcome alone; a cumulative seal re-counts every earlier delta per emission and identical outcomes on one action double-increment the fan's write.
- Presence is a HINT and the durable register is AUTHORITY — an authorization or admission gate reads the durable membership register alone and never a TTL-expiring, forgeable awareness channel; the ephemeral channel serves display (who is here, who follows) and its expiry or forgery therefore costs a stale cursor, never a granted capability. Instantiated at `Collab/session.md`; binds every ephemeral/durable pair the corpus grows.
- A veto edge whose args type DERIVES from its receipt args type narrows to the derived type — a base-typed probe accepts both edges and silently never reaches the cancel slot; instantiated at `Editing/inspector` over the grid's cancelable command pair.
- A platform-capability gate reads the capability PROPERTIES the operation needs AND the operation's activation preconditions, never a provider type test — the Avalonia no-op storage provider is `internal`, so a type test is unspellable outside its assembly AND the weaker predicate, and the live embedded provider answers every capability true while a picker launched on a windowless root returns a task that never activates, so the property read alone admits the worst failure shape; instantiated at `Shell/dialogs` (`DialogTopology.Windowed` beside the capability columns), binding every capability probe over a foreign floor.
- A meter delegate's arity mirrors its instruments' declared `Dimensions`, and a runtime meter column carries `(string instrument, Option<(string Slot, string Value)>)` — wider invites an untagged write against a declared breakdown, narrower makes a declared breakdown unwritable, and a bare tag value can neither check against the declaration nor express a zero-dimension row; instantiated at `Shell/navigation`.
- Capability admission folds every TOTAL gating plane through one predicate — a health-derived `DegradationLevel` is one plane and never the whole fact (its `Full` row retains every capability), so a structural plane — mount shape, isolation, tenancy — contributes its own roster-total set beside it; instantiated at `Shell/hosts` mount admission.
- Pose interpolation partitions by TYPE DOMAIN — `Render/animation` `TrackInterp` owns the AppUi stratum over `System.Numerics.Quaternion`/`ViewCamera`/`ElementPose`, `[NOT]` the kernel `MotionInterpolation` one-slerp law, which stays scoped to the kernel interior over `Plane`/`Rhino.Geometry.Quaternion`; the pressure earning the partition is per-sample `ViewCamera`-to-`Plane` marshaling plus the host-free-shell constraint.
- `Render/capture` owns the `NativeAssetFact` TYPE and `Shell/hosts` `NativeAssets.Identity` inside the mount transaction is its SOLE producer — a second same-shaped receipt record and a capture-side re-probe port are both the deleted twin.
- Popup, flyout, and tooltip motion has ONE owner — the package motion vocabulary through `MotionEasing`; the shipped Semi popup-animation style stays unmounted, because its inline duration literals would be a second untokened timing source.
- Semi slot re-emission writes the SEMANTIC brush layer only — the raw hue scale binds into the semantic brushes through `{StaticResource}`, so a runtime scale override re-tints nothing and a scale-targeted write is the deleted form.
- A shipped-theme token whose key names its own VALUE (a numeric step scale) is never re-seeded from a resolved metric — only role-named keys re-seed; re-seeding a value-named key makes the token lie about itself while passing every structural check.
- Alternative-input admission takes a cross-platform net10 SDK or nothing — an input modality whose only SDKs are per-platform (eye-tracking, exotic HID beyond the admitted SDL/MIDI/SpaceMouse set) stays excluded, because each admission mints a per-platform capsule with no shared decode, and the exclusion is stated at `Shell/input` as its own reason rather than a dangling roster token.
- A device case addressing two legs by one ordinal addresses the space BOTH legs enumerate — SDL's independent joystick and haptic index spaces are the archetype, and the defect is silent because a one-device machine pairs correctly; instantiated at `Shell/input`, binding every multi-leg device vocabulary.
- Where a field visualization samples is a `FieldSites` row, never a count — `Sampled` and `Declared` are two rows of one axis shared by `SimVisual.Streamline` and `SimVisual.Glyph`, so a topology-guided seeding declares its sites where the pass key, the receipt, and a viewpoint diff read them instead of hiding them in a delegate closure. A flow-topology visualization is therefore NOT a case: a Morse atlas renders as separatrix arcs through `Streamline` and classified fixed points through `Glyph`, and the atlas itself is projected upstream and crosses as `Declared` coordinates, so the never-re-computes law covers field ANALYSIS as well as field GEOMETRY.
