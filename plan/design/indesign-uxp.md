# [INDESIGN_UXP]

Specification for `@rasm/indesign`: a resident, transport-only UXP plugin (WebSocket client, job execution, one-line status panel) driving InDesign (`<indesign.processName>`) from a local MCP server. Every row names its source and date; status words are `proven` (this machine, this session), `documented` (URL, date fetched), `inferred`, `unverified`. Research date: 2026-09-11. Nothing was installed, run in InDesign, or written outside `<Sources>/design/`, where `<Sources>` = `plan/research/sources`.
