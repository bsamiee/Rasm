Design of `apps/creative-cloud`: one stdio MCP server, fifteen projects, the vocabulary, transport, job model, tool catalog, pipelines, and rule families. Source tags: `FH` = `.claude/plugins/function-hooks/`, `RI` = `rasm-integration.md`, `AS` = `applescript-integration.md`, `PR` = `probe-results.md`, `PS` = `photoshop-uxp.md`, `ID` = `indesign-uxp.md`, `IA` = `illustrator-acrobat-cc.md`, `NM` = a file under `node_modules` at the catalog version, `C7` = a documentation page fetched through context7 ([14]). `RI` [06], [07], and [09] are the repository facts and the proofs that decide every row they touch; a row with no proof yet names its step in [12]. ## [03]-[THE_ONE_VOCABULARY]

`host-bridge/errors.ts`, typechecked, Biome-clean, and ast-grep-clean (RI [09]-[31]). Every `BridgeError` variant takes the form `isolatedDeclarations` accepts (RI [03]-[15], [09]-[11], [09]-[13]): a fields interface, an interface `X extends Cause.YieldableError, XFields { readonly _tag: 'X' }`, and `const X: new (fields: XFields) => X = Data.TaggedError('X')<XFields>`; an exported `class extends Data.TaggedError(...)` is `TS9021`, a field named `message` is `TS2320` against `YieldableError.message`, so every text field is `reason`. `BridgeError` is one `type` union of the eleven interfaces; `classify(host, reply)` returns `Option.Option<BridgeError>` (`no-nullable-return` refuses `| undefined`, RI [09]-[07]). `host` is a `HostId` from the host table ([02] row 03).
