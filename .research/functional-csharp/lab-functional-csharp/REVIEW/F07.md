1. Location: line 47.
   Claim: "The Prelude ships `par` for every arity and bound-argument count, and `lpar`
   fixes the last argument."
   Evidence: `sigs/Prelude.txt` carries one `lpar` overload only —
   `public static Func<T1, R> lpar<T1, T2, R>(Func<T1, T2, R> func, T2 b)` (line 700).
   `par` covers `Func` arities two through ten with every bound-argument count (lines
   701-745) and the `Action` twins (746+). The sentence pairs the two and implies `lpar`
   has the same coverage.
   Correction: replace the sentence with "The Prelude ships `par` for each arity and
   bound-argument count, and `lpar` fixes the second argument of a two-argument function."

2. Location: line 201.
   Claim: "The runtime record holds the connection as stable configuration from startup."
   Evidence: the same section keeps the book bullet at line 180, "acquire a short-lived
   resource only when the operation runs", and Buonanno chapter 7 states "The actual
   connection is lightweight and short-lived: it is opened and disposed for each query
   rather than captured as configuration." The new sentence reverses that claim and
   contradicts the bullet four lines above it. `NOTES/F07.md` records the same gap under
   what a project still needs.
   Correction: replace the sentence with "The runtime record holds the capability from
   startup, and the implementation opens the short-lived connection when the query runs."

   `.scratch/lab-functional-csharp/F07/Root.cs`, and append one sentence to the paragraph
