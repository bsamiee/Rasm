Activation and Deactivation
When you start Adobe InDesign, you’ll see 'Designers Bookshop' in the menu bar. To activate the plug-in (demo or license), go to: Designers Bookshop > Grid Calculator Publishing Edition > Activate Plug-in.

The plug-in may not appear if Adobe InDesign was running during installation. If that happens, simply restart InDesign and the plug-in will load.

Activate Demo To activate the demo, enter your first name, last name, and email address. Then click 'Activate' and start the demo via the 'Open Plug-in' menu item.

Activate License To activate the license, enter your first name, last name, email address, and license key. Then click 'Activate'. If you've previously activated the demo and now want to activate or move your license, make sure to first select 'Deactivate Plug-in'.

Deactivate Subscription License Please note that deactivating a subscription license does not cancel your subscription. Deactivation simply allows you to move your license to another computer. To cancel your subscription, use the link provided in your receipt. Subscriptions renew automatically until canceled.

Power Tips
1. New Document
To create a new document simply open the plug-in, it will automatically create the new document for you (why not assign Cmd+N to Open ‘Plug-in’, via Keyboard Shortcuts > Product Area > Grid Calculator Publishing Edition).

2. Margins – Grid vs. Manual Values
The plug-in allows you to set exact desired margin values, you do not need to base any margin values on the document grid, simply check the box(es) ‘Value’ and it will switch to manual mode (this only works in setup mode: Quick, while Modular and Smart  strictly align with the document grid). The baseline grid/leading will automatically give you the perfect leading number when ’Value’ is applied to top and bottom margins.

3. Body Copy Automatically Snaps to Baseline Grid
The plug-in automatically creates the body copy for you and aligns to the baseline grid. If you edit your baseline grid the body copy will automatically update, that’s some truly dynamic, magical stuff!

Only edit Body Copy #1 within the plug-in, unless you're adjusting safe settings like Character Colour. Editing it elsewhere may break synchronization. If you want, you can create a secondary body copy where you are more free to edit settings.

4. Align Images and Text with Laser Precision
Align images with your body copy and baseline grid using ‘Image-lines’ (found in Paragraph and Character Styles section),
based on x- or H-height. In most cases you will use x-height. Align the top of the image on one of the image-lines (guides)
and end the image on the baseline grid and voilà, perfect alignment between images and text!

5. Setup Modes; Quick, Modular and Smart
Quick Mode is the simplest, while Modular and Smart are more advanced. I highly recommend experimenting with them. Modular and Smart are synced, so you can switch between them freely, while Quick Mode operates independently.

6. Dynamic indents, exdents and tabs
Since the entire layout is synchronized from a single dialog, you can dynamically adjust it as needed. In the Paragraph and Character Styles section, use the dropdown for Exdent, Indent, and Tabs.

H. Subdiv simply means Horizontal Subdivision and means the width of the small document grid square, while Em or Ems means em space which equals the font size. If you make any changes make sure to open the Paragraph and Character Styles section to reflect those changes to your body copy.

7. Presets – reuse layouts over and over!
Find yourself using the same layouts repeatedly? Or simply want to build a library of go-to layouts? Then you’re going to love presets. Instead of scattering layouts across separate documents, create any layouts you want and save those layouts as presets, you can even organise presets based on clients.
