# [PUBLICATION]

Build an editable document from the requested content, audience, reading conditions, and deliverables. Preserve source copy and existing relationships outside the requested change.

## [01]-[BRIEF]

Resolve decisions that change document structure before composing pages:
- Establish trim, binding, bleed, and production requirements for printed work
- Establish viewing distance, display proportions, and reading pace for presentations
- Establish reader, navigation, and accessibility requirements for digital documents
- Identify supplied copy, assets, examples, and constraints that remain authoritative

For existing work, establish native page, parent, layer, style, story, and link relationships before changing shared definitions. For supplied examples, derive hierarchy, measure, spacing, image spans, and recurring page roles from actual content and native settings. Treat example dimensions and font ratios as design choices.

## [02]-[DESIGN]

Assign roles to content before formatting: sustained reading, display text, navigation, evidence, captions, and annotations. Preserve meaningful source order. Choose type contrast through size, weight, spacing, and position; use available faces and intended variable-font instances.

Compose representative headings and body passages to choose reading measure and leading. Judge dense pages at their intended viewing size. Establish margins from content, binding, and trim; reserve recurring space for folios, headers, captions, and navigation.

Choose a grid for relationships the content needs. Coordinate interval and origin when baselines, modular rows, and image edges must align. Use glyph-top alignment when a visible letter edge defines the relationship; use baselines for text rhythm. Preserve intentional asymmetry rather than aligning every edge by default.

## [03]-[STRUCTURE]

Build recurring page roles with parents and reusable guides. Separate layers by editing and output responsibility. Use native story threads for continuous reading and independent frames for independent content. Select frame auto-sizing, primary flow, or Flex according to the relationship that must survive editing.

Define paragraph roles, sparse character emphasis, frame behavior, and table regions through their native styles. Derive related variants through inheritance. Use native list numbering, generated contents, variables, and cross-references when content must update. Choose automatic formatting only for repeatable rules that remain valid after edits.

Retain editable text and linked assets. Choose image fitting from image purpose, then judge the visible subject before allowing a fill operation to hide edges. Establish color and transparency decisions from the intended output.

## [04]-[COMPOSITION]

Compose actual demanding cases before extending shared definitions: dense copy, a long heading, a short page, a figure with caption, and required tables or lists. Empty placeholders cannot establish fit.

Read composed lines, baselines, overset, and thread order alongside complete page or spread images. Judge hierarchy, spacing, image emphasis, and sequence together. Correct recurring problems at the owning style, parent, frame, or source relationship.

Extend the document after representative compositions work. Refresh generated text after pagination changes. Finish with output requirements satisfied and report actual deliverables, unresolved source constraints, and decisions the user must retain when editing.
