# [SWIFT_PRINCIPLES]

Rules a module-by-module rebuild of `libs/swift` and its consumers follows.

1. Each module owns the host plumbing of its concern and builds on whole layers beneath: `Results` and `Encoding` import no host framework, `JSONRPC` frames one envelope, `CurrentProcess`, `Files`, `Processes`, `Applications` and `AppleEvents` each own one host API (os and the responsibility SPI; FSEvents and the lock protocol; `Subprocess` and process termination; `NSWorkspace`, `NSRunningApplication`, the AX API, ScreenCaptureKit and the font catalog; Apple events and scripting definitions), and `tools/watch-apps`, `apps/macos/relay` and `apps/creative-cloud/atelier/macos` compose them. App content sits in the composition: the `/usr/bin/security` keychain protocol Relay's trust rule names, Claude Code's lock paths and backoff numbers, Adobe's bundle prefix, activation stems, sdef codes and `DjxM` script event, Atelier's request vocabulary with its walk predicate and PNG policy, watch-apps' notification subset
2. Exit reads off the main run loop go through `proc_pidinfo`, which `NSRunningApplication.isTerminated` lags
3. Apple-event specifier forms and codes come from the SDK's `form*` and `kAE*` constants, and the refused `kAXRaiseAction` has one owner
4. `Unmatched`'s ambiguous case keeps the wire's `subject: "single <subject>"` spelling
5. `CancellationError` is the one cancelled case, and no reason case restates it
6. Actors caching an in-flight `Task` evict it on failure
7. `JSONValue` holds one numeric case, and a tagged union encodes its `_tag` through one generic envelope
8. Process termination with its status is one public stream in `Processes` over kqueue `EVFILT_PROC` `NOTE_EXIT`, read by `Applications`, with each wait status decoded once into `TerminationStatus` and a `NOTE_EXIT_DETAIL` option set. A parent-exit watch with no status keeps `DispatchSource.makeProcessSource`
9. AX notifications an observer watches and the poll interval are composition parameters
10. File watches keep FSEvents' per-event flags and read paths through `kFSEventStreamCreateFlagUseCFTypes`. Lock protocol steps stay byte-compatible with Claude Code's (non-recursive `mkdir` of `<file>.lock`, the stale mtime test, the mtime heartbeat, compromise on a changed mtime, remove on release, the `max(stale, 2s)` and update clamps, `realpath` canonical paths), and inode identity, mode, logging and the retry schedule are local. Backoffs are values of count, base, growth factor, cap and jitter
11. CF reads check `CFGetTypeID`, and an SPI with no public counterpart (`_AXUIElementGetWindow`, remote tokens, `responsibility_spawnattrs_setdisclaim`) is declared once in the form the manage-repo skill's Swift reference states
12. `errorUserInfo` is a `switch`, CasePaths serve a projection a reader makes, and AsyncAlgorithms members sit in the module that composes streams
13. `Xcode.xcconfig` `SWIFT_WARNINGS_AS_ERRORS_GROUPS` names the groups `Package.swift` names
14. Wire to TypeScript stays byte-identical in every key, `_tag`, case and enum spelling the readers decode (`@rasm/automation`, `@rasm/search`, Atelier's status read, effect's `RpcSerialization` for JSON-RPC messages, `.claude/skills/watch-apps/SKILL.md`), and the encoding behind a spelling can change

## [01]-[FRAMEWORK_USE]

Code reaches each framework and package through its members in the macOS 27 SDK or the pinned checkout, and hand code stands only where a family names it:

15. AppKit and ApplicationServices: `NSWorkspace.shared.openApplication(at:configuration:)`, `observe(\.runningApplications, options: [.initial, .new])` (accessory policy needs the filter `DidLaunchApplicationMessage` lacks), `urlsForApplications(withBundleIdentifier:)`; `AXObserverCreate` with a run-loop source, `AXUIElementCopyAttributeNames`, `AXUIElementCopyActionNames`, `AXUIElementCopyMultipleAttributeValues` keeping its `AXError`, `AXUIElementIsAttributeSettable`, `AXIsProcessTrustedWithOptions` under `kAXTrustedCheckOptionPrompt` through `@preconcurrency import ApplicationServices` as the one trust member
16. ScreenCaptureKit and CoreText: `SCScreenshotManager` over the caller's `SCScreenshotConfiguration` (`dynamicRange`, `showsCursor`, `contentType`, `destinationRect`), every `SCScreenshotOutput` member returned (`sdrImage`, `hdrImage`, `fileURL`); `CTFontDescriptorCopyAttribute` per face attribute, `CTFontDescriptorCopyAttributes` holding the name alone
17. Foundation and Dispatch: `FileManager.enumerator(at:includingPropertiesForKeys:options:errorHandler:)` listing an absent root as empty through `ifPresent`, `NotificationCenter.default.messages(of:for:)`, `NSMetadataQuery` for a name search, `NSAppleEventDescriptor.sendEvent(options:timeout:)`, `CreateObjSpecifier` and `CreateOffsetDescriptor`, `realpath` for canonical paths, `DispatchSerialQueue` as an actor executor, synthesized `Codable` over a plist read once. By hand: a race and a timeout (no timeout in `_Concurrency` or AsyncAlgorithms), the accumulated failure and `combine` (no `Result` aggregate in the standard library), the kqueue `EVFILT_PROC` wait for a non-child's exit status (`makeProcessSource` reports none), the lock protocol steps, a `JSONValue`-backed `Decoder`, a hex codec (no member encodes a byte sequence as hex)
18. Subprocess, AsyncAlgorithms, CasePaths, OrderedCollections: `Subprocess.run` with `Executable.path`, `Environment.custom`, `PlatformOptions.teardownSequence`, `SubprocessOutputSequence.strings(separatedBy:)`, `TerminationStatus`; `chain`, `merge`, `removeDuplicates`, `reductions`, `AsyncTimerSequence`, `.async`; `@CasePathable` with `.is` and `[case:]`; `OrderedDictionary` and `OrderedSet` where order is read

## [02]-[LAYOUT]

19. `JSONRPC` sits under `core` and imports no host framework: it takes lines in as `some AsyncSequence<Data>` and a writer out as a value, logs nothing, and the consumer binds it to a `Subprocess` execution or file handles
20. `Package.swift` lists each module as `.target(name:dependencies:path:)` in `modules`, products derive from `modules`, every `.target` takes the shared `settings` and linker settings, a package product appears in a module's dependencies only where a member of it is called, and a merged module takes the dependencies its files call. The `.xcodeproj` `package-product-members` rows and `xcshareddata/swiftpm/Package.resolved` follow through `xcrun xcodeproj pkg link` and `upgrade:xcode`
21. Consumers take the rebuilt forms in `tools/watch-apps/WatchApps.swift` (the `Line` encoder, `Set` and `Target` names, trust check, launch), `apps/macos/relay` (`CodexClient` over the one connection, backoff values, keychain and lock protocol kept as app content), `apps/creative-cloud/atelier/macos/Atelier.swift` (request vocabulary, walk predicate, PNG policy, Adobe rows) and each module importing a rebuilt module
