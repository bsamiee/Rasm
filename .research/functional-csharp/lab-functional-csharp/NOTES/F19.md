## Observed behavior and corrections

- `Source<A>.Combine(rhs)` is sequential concatenation. Decompile of `CombineSource<A>.ReduceInternal`: a `foreach` over `Sources` awaits each source's reduce in order before the next starts. `Source.pure("prompt").Combine(rest)` collected `["Enter a currency pair", "1.1", "unknown currency pair"]` in that order. This is the `StartWith`/`Concat` form. `Source.merge` interleaves, so the sample sums the merged values instead of comparing an order.
- `Source.lift(IObservable<A>)` subscribes when the source is reduced. Decompile of `ObservableSource<A>.ReduceInternal`: `await foreach (A item in ObservableExt.ToAsyncEnumerable(Items, e.Token))` inside the `IO`. Nothing is subscribed at `lift`.
- `Event<A>` buffers. Decompile: `Subscribe()` creates an unbounded `Channel<A>` per subscription and registers it in an `AtomHashMap`; the joined delegate writes to every channel with `TryWrite`. A sequential `Subscribe()`, then invoke the delegate, then `Take(1).Last()` needs no fork. `Event(ref Action<A>)` uses `Delegate.Combine`, and `Dispose()` uses `Delegate.Remove` then `UnsubscribeAll()`. The lab holds the `Event` in a static readonly field so the delegate is joined once (a property would join a new `Post` on every read).
- `source.Zip(source.Skip(1))` over one lifted source yields `[(1, 2), (2, 3)]`: each side of the `Zip2Source` reduces the source on its own, so a replayable source is read twice. The plan's "Reduce into a Seq then Zip(seq.Tail)" is therefore not needed for the stream form; the `Seq` form (`balances.Zip(balances.Tail)`) is used inside the ledger sample over the scanned balances.
- Buffer retention with every `Post` before `Reduce`: `Unbounded` kept `[1.1, 1.2, 1.3]`, `Latest(0m)` kept `[1.3]` (the seed is not emitted), `Newest(2)` kept `[1.2, 1.3]`. With the reducer forked first, `Bounded(2)` and `Single` drained all three in order. This matches the F22 findings.
- There is no `LiftIO` or `liftIO` for `Source` in the streaming assembly (`ilspycmd` over `LanguageExt.Source` shows no such member, and `Prelude` has none for `Source`). The `SelectMany` sample therefore binds each pair to an inner `Source<decimal>` built by `Source.lift(Seq)`, not to an `IO<decimal>`. The plan's `Source.Bind` over an `IO` does not exist; `Source<A>.Bind(Func<A, Source<B>>)` is the declared form and LINQ query syntax compiles through `SelectMany`. The instance `Bind` is not called by name in the lab, so the doc names the query and `SelectMany`, not `Bind`.
- `toSeq(hashMap)` is ambiguous (`HashMap<K, V>` implements both `IEnumerable<(K Key, V Value)>` and `IEnumerable<KeyValuePair<K, V>>`), so the ledger reads `toSeq(ledger.Filter(Crossed).Keys)`. The plan's `Choose` over the balances is replaced by `HashMap.Filter(Func<V, bool>)` then `Keys`, which compiles and returns the crossing accounts.
- The overdrawn sample keeps every amount per account (`HashMap<Guid, Seq<decimal>>`) rather than one balance, because a crossing from nonnegative to negative is a transition between two adjacent balances and the final balance alone cannot show it. `Seq.Scan` emits the seed first, which is the book's explicit `StartWith(0m)`.
- Analyzer rulings met: a static lambda reading a static field (`onMessage`) is non-capturing and compiles as `static`; `IDE0200` demands the method group `quotes.Post` inside `TraverseM`; a discard parameter next to a named one (`static (_, rate) => ...`) compiles; `decimal.ToString(CultureInfo.InvariantCulture)` replaces an interpolated numeric hole.

- The time-bounded `Take(maxDelay)` pair sample (`quickPairs`): `Source<A>.Take` takes a count only, and no `Source` member bounds a window by time. The sentence about the time window is removed and the multi-key recognition sentence stays.

## What a project built on this file still needs

- A host adapter that disposes the `Event` when the producer detaches, and one that owns the `IDisposable` returned by a raw `Subscribe`.
- A buffer choice passed as a value (`Buffer<A>`) from configuration, and the consumer forked before posting whenever `Bounded` or `Single` is chosen.
- A time-windowed pairing, if required, built in the host over `IAsyncEnumerable` with a clock passed as an argument, then lifted with `Source.lift`.
