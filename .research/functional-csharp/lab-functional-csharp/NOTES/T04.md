## Lab rulings

Lab at `REPO/.scratch/lab-t04` (`LabT04.csproj`, `Program.cs`, `T04/*.cs`, `T04/Samples.cs`). Build: 0 warnings, 0 errors. Run: exit 0, all checks pass. Lab block files are byte-identical to the draft fences plus a `namespace Lab.T04;` header.

- CA1054/CA1056: property `Urn` and parameter `urn` flagged as URI-like strings. Renamed the type to `FileLocation` with `Store` and `Path`.
- CA1308: `value.ToLowerInvariant()` in `Slug.Validate`. Removed the normalization, `Slug` round-trips unchanged.
- CA1508: `item is null && value is not null` after a `switch` reported as dead code. Rewrote `ShippingMethod.Validate` and both `Dual.Validate` with an early `if (value is null)` block.
- CS8826: `ValidateFactoryArguments(ref ..., ref string fileStore, ref string path)` must match the generated parameter names. Renamed to `store`.
- RCS1078: `string.Empty` in a tuple. Replaced with `""`.
- RCS1014 with `roslynator_array_creation_type_style = explicit` and `IDE0300` (`dotnet_style_prefer_collection_expression = when_types_exactly_match:error`) reject `[(byte)Key]`, `new byte[] { (byte)Key }`, and a typed local. Replaced the `byte[]` factory with a `char` factory.
- MA0003: literal `null` arguments must be named. `ShippingMethod.TryParse(slug, provider: null, out _)`, `ShippingMethod.Parse(slug, provider: null)`, and the prose spellings of `Parse(..., provider: null)`.
