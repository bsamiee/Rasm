## [05]-[PROCESS]

- Every provider, store, session, or signing handle carrying account or credential state binds per composition, never as a process-global default — in-process isolation is an `anyio` resource guard on the mutable write path, cross-process coordination stays the store or format's own optimistic-commit protocol, and conflict-retry telemetry never substitutes for the guard.
- `KernelTrait` selection reads the provider's GIL behavior alone — payload weight, artifact importance, and call frequency never select the band, because a heavy GIL-releasing call serializes nothing while a light GIL-holding loop starves the event loop.
- Import deferral speaks the `lazy` module-top proxy by default — a function-local `# ruff:ignore[import-outside-top-level]` import is earned only by a package banned at module scope whose transitive load cannot survive import time; an unearned function-local import hides the deferral from the module-top roster a floor audit reads.
