# F05 notes: sequences and LINQ

Lab `Lab.F05` builds with zero diagnostics and runs with exit 0. `Samples.Run()` checks every sample outcome.

## Members verified

- `Seq<A>.Filter(Func<A, bool>)`: instance, returns `Seq<A>`.
- `Seq<A>.Map(Func<A, B>)`: instance; a method group (`Map(Normalize)`) binds.
- `Seq<A>.Map(Func<A, int, B>)`: instance, indexed `(value, index)`.
- `Seq<A>.Bind(Func<A, Seq<B>>)`: instance, flattens.
- `IEnumerable<A>.AsIterable()`: `IterableExtensions`, returns `Iterable<A>`.
- `Iterable<A>.Map(Func<A, B>)`: abstract instance; a method group (`Map(First)`) binds through a three-stage chain.
- `Iterable<A>.ToSeq()`: `FoldableExtensions`, materializes the chain into `Seq<A>`.
- `Seq<A>.Fold(S, Func<S, A, S>)`: `FoldableExtensions`, left fold; a tuple seed `(Budget: 0.0m, Revenue: 0.0m)` folds two totals in one pass.
- `Seq<A>.FoldBack(S, Func<S, A, S>)`: `FoldableExtensions`; `Seq(1, 2, 3).FoldBack(Seq<int>(), (acc, x) => acc.Add(x))` is `[3, 2, 1]`.
- `Seq<A>.Fold()` seedless under `A : Monoid<A>`: compiles; see the correction below for its order.
- `Seq<A>.At(Index) : Option<A>`: `FoldableExtensions`; `At(0)` on an empty `Seq` is `None`, and `Bind` then skips `At(middle - 1)`, so the median of an empty sequence is `None` without an `Index` exception.
- `Enumerable.Order()` on `Seq<int>` then `toSeq(...)`: the sorted `Seq<int>`.
- `Seq<A>.Zip(Seq<B>) : Seq<(A First, B Second)>` with `Seq<A>.Tail`: adjacent pairs.
- `Seq<A>.Tail` on an empty `Seq`: returns an empty `Seq`, no exception (`AnyAdjacent(Seq<int>(), ...)` is `false`).
- `Seq<A>.Exists(Func<A, bool>)` and `Seq<A>.ForAll(Func<A, bool>)`: instance quantifiers; `ForAll` over zero pairs is `true`.
- `LanguageExt.List.unfold<S, A>(S, Func<S, Option<(A, S)>>)`: yields the `A` of every step; `unfold(1, s => s <= 16 ? Some((s, s * 2)) : None)` under `toSeq` is `[1, 2, 4, 8, 16]`.
- `Option<A>` LINQ query: six `from` clauses over `Option` bind through `SelectMany` and `select` builds the record.
- `parseInt(string) : Option<int>` inside a `static` lambda under `Option<string>.Bind`.
- `Seq<A>.Traverse(Func<A, K<Option, B>>)` with `.As()`: `Option<Seq<Story>>`; one `None` record makes the whole result `None`.
- `Prelude.Map<K, V>()`: the empty `Map` as a fold seed.
- `Map<K, V>.AddOrUpdate(K, Func<V, V>, V)`: instance; a tuple literal binds the `V` overload with no ambiguity against `Func<V>`.
- `Map<K, V>.ToSeq() : Seq<(K Key, V Value)>`: instance, key order, so the report lines come out by season.
- `Prelude.Map((k, v), (k, v))` and the `Map<K, V>` indexer: used by the samples only.
- `string.Create(CultureInfo.InvariantCulture, $"...")`: decimal holes; `4m / 8 * 100m` renders `50.0` and `0m` renders `0`.

## Corrections to the plan and the API document

- CORRECTION (finding): the seedless monoid `Fold()` combines each element in front of the state. `Seq(Seq(1), Seq(2, 3)).Fold()` is `[2, 3, 1]`, not `[1, 2, 3]`. The doc names only the seeded `Fold` and `FoldBack`; the sentence on the seedless overload is removed.
- CORRECTION (plan): there is no `Seq<A>.Sort` instance member. `Prelude.Sort<OrdA, A>(this Seq<A>)` exists and compiles as `numbers.Sort<OrdInt, int>()` with a file-level `using LanguageExt.ClassInstances;` (probe compiled, then removed). Its body is `xs.OrderBy(identity, OrdComparer<OrdA, A>.Default).AsIterable().ToSeq()`. The doc uses `Order()` from LINQ with `toSeq`, which needs no witness and no extra namespace.
- CORRECTION (plan): `Traverse(ParseStory)` as a method group fails with CS0407 ("has the wrong return type"); the lambda `Traverse(static line => ParseStory(line))` infers `F` as `Option`.
- CORRECTION (plan): `OrderBy(static number => number)` fails MA0159 ("Use 'Order' instead of 'OrderBy'") and RCS1077. `Order()` is the form that compiles.
- Refinement of the RCS1124 ruling: a local consumed once by the next statement did not fail when the use sits inside a larger expression (`Seq<Priced> priced = normalized.Map(...)`, `return priced.Map(Render)`, `return transformed.ToSeq()`, `return string.Join(Environment.NewLine, lines)`). The named-stage samples keep their locals.
- `Sum()` and `Average()` on `Seq` were not re-probed; the F08 ruling (CS0121) stands and the doc aggregates with `Fold`.
- MA0007 requires a trailing comma after the last value of an object initializer; the `MakeObject` block carries it.
- A record built through an object initializer declares `required` init properties (`ComplexObject`), so no default value is needed.

## Still needed by a project built on this file

- A file boundary: the CSV text enters as a `string`; a host reads it through `File<RT>` under `Eff<RT, A>` or an `IO<string>` and passes the value in.
- A reason for a failed parse: the pipeline returns `Option`, so a project that must report which line failed changes `ParseStory` to `Fin<Story>` with an `Expected` error and `Traverse` under `Validation<Error, A>` to accumulate every bad line.
- A real CSV reader for quoted fields and embedded commas.
- A sort with a domain order: `Prelude.Sort<OrdA, A>` with an `Ord<A>` witness, or `Order()` with a comparer.
