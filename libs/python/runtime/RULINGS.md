## [02]-[SHAPE]

- `measured`'s free `scope` parameter carries the branch telemetry grammar the hook, meter, and instrument owners already enforce — `rasm.`-rooted lowercase dot-segments; a bare package-prefixed scope entering the exported weave forks the branch's one telemetry namespace.
- Every new blocking concern earns its own named `CapacityLimiter` sized by its owner, and the anyio ambient default thread limiter stays refused branch-wide — an unnamed shared limiter lets one concern silently oversubscribe the host against every other.
- `Hlc` samples this branch's own admitted clock for local events and merges every inbound stamp before `tick` — the join-semilattice over `(physical, logical)` converges under independent physical mints, so a privileged single physical authority buys no ordering guarantee while making a Python-only deployment impossible; re-litigation opens only if merge stops dominating on the physical half.
- Wire integers above the `int64` band carry the `ge=0` floor alone with the ceiling enforced by the railed decode — msgspec meta expresses no above-`int64` bound, so an above-band ceiling annotation is a phantom the decoder never enforces; an in-band ceiling (`I63`) rides `Meta(le=...)` and is enforced.
- Telemetry install failure policy is fail-before-publish — `_pipeline` completes provider construction before `_commit` publishes, because the OpenTelemetry globals (`set_meter_provider`, `set_tracer_provider`, `set_logger_provider`, `propagate.set_global_textmap`) are set-once surfaces with no unset member; a demanded post-publication rollback compensates through a phantom inverse and is void, the real hardening moving work before publication; re-opens only when the SDK ships a public unset.
- OTLP is the one log egress door and the console line is operator residue — the deployed collector admits an OTLP receiver alone, with no stdout, filelog, or journald receiver on any pipeline — so a ship row that silences the console stays refused as well: the console handler's `ProcessorFormatter` is the only seam a foreign stdlib record crosses the shared chain through, and silencing it silences the foreign leg's wire projection with it.
- Log posture folds rather than partitions, because the stdlib root handler roster is process-global: every live composition's request meets at the strictest reading per column — the finest floor, the tightest payload caps — with the egress arming as a union, so an embedded composition can neither silence a host's floor nor loosen its bound, and a composition self-identifies through the `composition` field its bound logger carries.
- `LogLimits` stays a page-owned policy shape rather than the SDK record-limit type it mirrors — importing that type reifies the cold `sdk._logs` tier in every composition root against the lazy law telemetry holds — and the SDK's env-resolved instance stands behind the wire as the deployment ceiling.
- Payload bounds ride a CHAIN row, never a step inside the wire projection — both renders read one already-narrowed value, so console and wire cannot disagree and the degrade holds one form. Bounding at the projection instead leaves the console serializing the raw event, where a self-referential or input-scaled structure raises `RecursionError` out of the log call that `logging` re-raises rather than handles. Depth, width, and byte length stay branch-owned: the SDK cleaner truncates `str` alone.
- Log egress arms by chain MEMBERSHIP, never a per-event branch — `shared_chain` rebuilds on every configure under the folded posture, so the wire rows seat only where that fold armed them, an unarmed process allocates nothing per line and reads no custody state, and the caps the rows need bind once at build rather than resolving per event. Custody-read branching inside a terminal row charges every event of every composition for that lookup and leaves the wire's private slots standing for the console render to find.
- Wire-bound values coerce to shapes both consumers keep whole — the record cleaner types a collection off its first non-null element and drops the WHOLE value on the first element of another type, so a mixed collection projects onto an index-keyed mapping rather than reaching the wire as null while the console renders it entire, and leaf conversion rides the receipt encoder's own so an enum, timestamp, UUID, or decimal lands as the value that encoder writes rather than as repr text both renders then carry.
- Terminal interpreter doors belong to the log egress — an uncaught raise, a dead thread, a finalizer's unraisable, and a raised warning each write past the whole handler roster to stderr by default, so the pipeline owner wraps each door and CHAINS the predecessor rather than replacing it, arming once with the first composition exactly as the egress union arms. Unwrapped doors lose precisely the lines an incident reconstructs from, and a door replacing its predecessor deletes an embedding host's own hook.
- Foreign `extra` mappings stay untrusted for every chain-owned key — `ExtraAdder` merges the mapping whole, so each row meaning one thing by a key writes it unconditionally, and `trace_context` is the sole writer AND sole eraser of the correlation roster: an invalid ambient span context strips those keys rather than leaving a caller's injected value standing as correlation this process is not inside.
- OTLP gRPC egress is refused on every forked or spawned worker floor — a persistent gRPC channel never survives `fork()` — so HTTP proto is the fork-safe default, `GRPC_ELIGIBLE` admits the gRPC transport only for the non-forking SIDECAR daemon, and install clamps every other profile's injected gRPC row back to HTTP with the receipt carrying the effective geometry, never a silent downgrade.
- Metric-stream shaping is data at the instrument owner and SDK objects at the install root — the per-instrument view rows and the tenant ceiling live beside the census table that generates them, and only the composition-root install names `View`, an aggregation, or a reservoir — because a `View` is SDK wiring and the branch admits none below that root; a view row hand-listed apart from the census silently lags it, and a shaping axis added to the SDK type instead of the row forks the two ends.
- Metric cardinality is bounded at two tiers because this SDK train ships no per-view numeric limit: the per-instrument allow-list closes the KEY axis and the tenant budget closes the one VALUE axis no allow-list reaches, folding an over-budget value onto the specification's own `otel.metric.overflow` marker at the single attribute fold every recording path shares. Enforcement homes at that fold rather than at each producer, and the budget is a profile policy value the install threads, never a literal; the row reopens when the SDK ships a view-level limit and the guard moves onto it.
- Wire temporality and aggregation preferences key the SDK instrument FAMILY classes and state every family the estate rules — the reader matches a preference key by identity and raises on the API base class each family derives from, so an API-spelled key is an install-killing raise rather than a quiet default, and an omitted family falls to the exporter's environment-seeded table where a deployment variable then owns a wire decision this branch pins. Both monotonic sum families and the histogram ride DELTA while both non-monotonic sum families stay CUMULATIVE, because a delta of a rise-and-fall sum reconstructs no level without a known origin; neither gauge family rows at all, a last-value stream exporting as a Gauge point that carries no temporality.
- Tag-partitioned counters carry the terminal partition alone and never the total those columns sum to — the admitted count is the denominator a receipt line reports beside its parts, and admitting it as one more dimension VALUE doubles every sum a board takes across that dimension. One literal owns the vocabulary and one named carve splits it, so a new disposition reaches the line and the counter from one member.
- Cross-cutting metric dimensions this branch mints carry no domain segment — the `rasm.<domain>.<measure>` grammar and its resolution gate bind SEGMENTED names, and a discriminant meaningful under every domain names no capability subject, so it rides the estate's unsegmented `rasm.<key>` shape beside the tenant dimension rather than earning a `DOMAINS` row that no query joins on.
- Measure shape decides the instrument class: a per-event delta records synchronously and a level observes — a delta held for the export thread republishes the last event forever, and a cumulative reader compounds that sawtooth into a monotonic total no producer emitted, while a level counted per event loses the occupancy it exists to report. Wire temporality per family is the preference-map row's, so a kind decision never restates one.
- Observable rows feed from a probe the EXPORT CYCLE calls, never from a value a producer pushes at its own call — a producer knows a level only at the instants it acts, so a pushed one publishes that instant until the producer acts again and a series named for a level reports a stale event. Owners of the bound resource register a bare non-raising read for their own lifetime and the callback folds every live probe under the scope; a push feeding an observable is the sawtooth defect wearing a level's name, doubling whatever terminal column already carries that event.
- Each producer's declared aggregation intent selects the census row's instrument kind — a sum intent is a monotonic counter, a last-value intent the synchronous gauge, and percentile, mean, and maximum intents all ride one histogram whose data point already carries min, max, sum, and count. Routing every measure through a histogram mints a distribution for a value that has none, and minting a second family for a maximum duplicates a moment the first already reports.
- One instrumentation-scope coordinate stamps every signal and its whole triple homes at the fault root — library name, distribution version, and semconv url bind through one helper at `reliability/faults#FAULT`, because `identity`, `clock`, `shapes`, and `wire` open spans from BELOW every observability owner and no import of theirs reaches a coordinate seated higher. Meter, tracer, and logger then carry one triple, a semconv bump lands at one constant, and no page mints the bare `get_*(name)` an unversioned schema-free scope a backend cannot join against its versioned siblings; seating the pair at an observability tier splits it from the `SCOPES` name it completes, and a per-owner version literal forks the three signals on the next bump.
- Evidence never sheds and its derived projection always may — the journal writer AWAITS a bounded intake so back-pressure suspends the producer, while the line and the series ride a fence whose fault is dropped; the `send_nowait` `WouldBlock` drop the high-frequency callback seam authorizes is exactly inverted here, because a lost dashboard point is a gap a reader tolerates and a lost fact is a billing or evidence defect nothing replays. Append attempts therefore never exhaust and the backoff caps, so a dead ledger costs a fixed cadence rather than a shed row.
- Shutdown closes the intake and awaits the drain, and a landing accounting for fewer rows than its batch offered is a failed attempt — `anyio` delivers every buffered fact once the last send end closes, so the partial window flushes losslessly where a cancelled drain scope drops exactly the buffer suspension protected, and a short landing retries safely because the content key dedups whatever already reached the ledger. That close RETIRES custody, so a later install re-arms the scope rather than adopting a closed stream every record then rails `resource` against, and every row a cancelled drain still owes — the batch in flight beside the checkpoint-free sweep of the buffer and the senders suspended behind it — stays readable as the one surface a root bounding that wait with its own cancel scope reads; a drain deadline parameter instead re-threads the cancellation a scope already owns and caps the steady-state retry the never-shed law forbids capping.
- `Ledger` is async whole and proves structurally at the bind — every member awaits because a ledger writes durably while the drain runs the loop, and this branch admits no on-loop blocking arm, so one synchronous member stalls the scheduler for a whole batch and a rail-returning member awaited as a coroutine converts to a fault the unbounded retry then chases forever. Admission resolves the port's own declared member roster, since an unchecked bind defers the missing-member raise into that same retry, where it is indistinguishable from a dead ledger. Emitter identity binds beside that ledger rather than resolving a module constant at write time, so a worker floor, an offline job, and a daemon each partition their durable rows under the identity they run as.
- Subject index rides the fact and its projected row, never a companion table — the portability export and the erasure key on one `(tenant, subject)` composite, so the coordinate finding a fact to export finds nothing to rewrite once the key dies and the two rights compose by construction. Indexing at a second relation instead obligates a ledger to write it inside the same landing, which the idempotent content-keyed append never promises.
- Journal order is the branch `Hlc` and journal identity is the content key over the deterministic payload — a ledger supplies neither, since Parquet on an object plane carries no identity column and no sequence spans two processes, so the stamp merges the inbound cause before ticking and the encoded preimage keys the row. Redelivery therefore lands duplicates rather than second rows, which is what makes the unbounded append retry safe; keying on a ledger-minted sequence forfeits both properties at once. Writers mint that stamp at admission and replace whatever slot a caller carried, because identity covers the stamped payload: a caller-threaded coordinate makes a discipline of what construction owes, and two producers reusing one collapse distinct facts onto a key that dedups genuine evidence away as redelivery.
- Erasure is key destruction and `open` is total over it — a destroyed or absent per-subject key folds to `Nothing`, the lawful state every reader renders through the receipts-owned marker, while an `InvalidTag` on LIVE material stays a fault, because collapsing tampering into absence renders a corrupted payload as lawfully erased. Every envelope binds its `SubjectKey` as associated data, so a ciphertext lifted onto another tenant fails its tag instead of opening under a key that happens to be live.
- Instrumentor train rows carry the driver they wrap and gate on its presence before reifying — a contrib instrumentor imports its driver at module scope, so one absent driver raises out of the composition root and takes every later row with it; the non-importing probe skips that row, keeps it out of the receipt, and activates it unchanged once the driver resolves.
- Scope handles mint once per module and never per call — the API caches none, so a per-call mint allocates on the emitting path, while the pre-install proxy a module-scope handle holds re-reads the global at every operation and upgrades at the install with no invalidation.
- Every instrument row proves its `DOMAINS` segment at IMPORT and the proof spans the whole table, never the mapped subset — Tier-0 refuses an unresolved segment at its declaration owner, and an observable row reaches an exporter with no census pair behind it at all. Filtering the unrostered row out of the derived census map inside a comprehension is the recurring wrong move — it reads as a harmless guard while it defers the failure to whichever producer records first, where a `KeyError` names the measure and never the missing roster row, and it strands an unmapped row's name past every gate. `DOMAINS` charter strings therefore stay non-empty, since the total read doubles as the comprehension's own select.

## [03]-[COLLAPSE]

- Content-key elision and RFC-9111 revalidation stay two cache owners with no overlap — the lanes cache short-circuits recomputation by content key before any transport, the HTTP cache revalidates freshness at the transport leg by protocol; neither substitutes for the other, and an acquisition consults the content key first.
- Trace-span ownership stays partitioned by `SpanKind` at its four boundaries — serve interceptor SERVER, capability-invoke interceptors CLIENT, wire decode CONSUMER/PRODUCER, `traced_kernel` INTERNAL; one unified tracing aspect mis-kinds boundary spans and re-parents spans the serve interceptor already parented, breaking the OTLP parent-child topology every backend reads.
- `loky` and `pebble` stay two admitted executors — neither package carries the other's capability (crash-respawning warm reuse; terminal wall-clock kill with worker recycle), so one merged executor forfeits one of the two guarantees; re-opens only when one package gains the other's guarantee.
- Log-record exception semantics stay the SDK's — the emit seam takes the RAISED OBJECT and derives the module-qualified type, the message, and the stack under the specification's own attribute names, so the chain resolves `exc_info` down to that one object ahead of the renderer that consumes the slot and hands it across. Page-spelled exception constants re-derive from rendered frames instead, taking the unqualified type name, dropping the stack entirely, and buying a package admission for a projection the SDK already ships.
- Stdlib-handler log bridging collapses into the chain's terminal projection row: the SDK's handler is deprecated at the pinned release, its named successor package is unadmitted, and a handler-shaped bridge reads a stdlib record after the render rather than the assembled event, so it can carry neither the redacted attribute projection nor the payload caps; the row emits through the logs API instead, and the logging owner's SDK import disappears with it — which is also what keeps the cold `sdk._logs` tier unreified outside the install.
- `BoundaryFault` stays the one union every package returns through — per-package fault types break the cross-tier `combine`/`aggregate` fold at composition roots, so a new failure family lands as an ingress class or case on the one union, never a sibling type needing a translation adapter.

## [05]-[PROCESS]

- Every `Metrics.record` call lands with its `INSTRUMENTS` row in the same pass — the public `MEASURES` map keys on `(domain, measure)` and raises on an unregistered pair, so a dangling record, a measure recorded under a domain that does not own it, and a row whose segment `DOMAINS` never admitted are each a producer-killing runtime fault rather than a silent no-op; the row is the record's admission, never an optional follow-up. `MEASURES` values ARE the census rows, so a producer's composition gate resolves that one map for the whole descriptor rather than re-deriving the filter beside its charter.
