## Members verified

- `Seq<A>.Map<B>(Func<A, B>) : Seq<B>`: the tuple pipeline runs two `Map` steps over a `Seq<int>` and returns `Seq<string>`; a tuple with named elements is the intermediate value.
- `Seq<A>` as a record field and as a struct field: `Seq<string> Cast` in a `readonly struct` with readonly fields, in a `readonly struct` with `init` properties, and in a `sealed record` copied with `with`; `Seq<string> == Seq<string>` compares the shared value.
- `Seq<A>.Count`, `Seq<A>.Head : Option<A>`, `Seq<A>.Last : Option<A>`, `Option<A>.Exists`: the sample reads the rendered lines.
- `Prelude.Seq(...)`, `Prelude.Seq<A>()`, `Prelude.HashMap((K, V), ...)`, `HashMap<K, V>.Find(K) : Option<V>`, `Option<A>.IfNone(A)`: the `Catalogue` stub that stands in for the book's undefined `GetFilm` and `GetCastList`.
- `Option<A>.Match(Some:, None:)`, `Fin<A>.Match(Succ:, Fail:)`, `Either<L, R>.Match(Left:, Right:)`, `Validation<F, A>.Match(Fail:, Succ:)`: the four shapes the "Modeling alternatives" sentence names, each read through `Match` in `Alternatives.cs`.
- Declarations, from the decompiled signatures: `public readonly struct Option<A>`, `public abstract class Fin<A>`, `public abstract record Either<L, R>`, `public abstract record Validation<F, A>`; the doc sentence matches the API document rows.
- Lifts: `Fin<int>` from an `Expected` subclass, `Validation<Error, int>` from `int` and from an `Expected` subclass, `Either<string, int>` from `Left(string)` and `Right<string, int>(int)`, `Option<int>` from `None`, `Pure(x).ToFin()`.
- `Prelude.Optional(A?) : Option<A>`: `Optional(null)` is `None`, `Optional("Simon") == Some("Simon")`; the closing sentence of "Nullable reference types" names it.

## Corrections and confirmations

- `Validation<Error, int>.Success(4)` does not construct a value: the name binds to a `Match`-style overload and fails CS1503. The implicit lift `Validation<Error, int> valid = 4;` is the construction.
- MA0127 rejects a constant string subpattern inside an `is` pattern expression (`account is MonopolyPlayersBankAccount { Player.FirstName: "Simon" }`) but accepts the same subpattern as a switch-expression arm. The `IsSimon` sample is a switch expression with a `_ => false` arm; `CurrSquare: not "InJail"` inside `CalculateInterest` compiles unchanged.
- MA0101 rejects the book's verbatim multi-line interpolated string (`$@"..."`); the second `Map` joins three interpolated lines with `Environment.NewLine`.
- IDE0048 demands parentheses around `p.BonusInterestRate * 1.25m` inside the sum.
- MA0007 demands a trailing comma after the last switch arm and after the last `with` initializer.
- CS8618 fires on non-nullable `init` properties of a record class; `required` on `Title` and `Director` satisfies it. The `readonly struct` with `init` properties compiles without `required`.
- CA1852 and MA0053 demand `sealed` on the record `Movie`.
- IDE0130 rejects a namespace that does not match the folder, so the three `Movie` types live in `F04/Fields`, `F04/Init`, and `F04/Records` under `Lab.F04.Fields`, `Lab.F04.Init`, and `Lab.F04.Records`. The doc blocks are unchanged by this: the namespace line is lab scaffolding.
- `string.Join(", ", x.Cast)` with `x.Cast : Seq<string>` resolves to the `IEnumerable<string>` overload.
