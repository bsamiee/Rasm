# Review charter — Rasm

Repo law rides the files.json reads: `CLAUDE.md` owns execution and code-generation law, `AGENTS.md` owns the load order and engineering contract, the root `README.md` owns workspace topology, `libs/.planning/campaign-method.md` is the review standard for all design-corpus work under `libs/`, the docgen defect catalog (`.claude/skills/docgen/references/defects.md`) names the prose defect classes durable markdown answers to. Judge every diff against those files and the `docs/stacks/<language>/` doctrine they route to, never against generic community convention. Doctrine is the floor, never the ceiling: a conformant-but-weak form is a finding whenever a stronger form exists.

A design corpus is the reviewable surface — markdown planning pages whose embedded code fences are the work product — with workflow and tooling JavaScript and configuration. Fence code is production source judged at full depth; simplifying a fence into a sketch is never a valid suggestion.

## [01]-[STANCE]

- Presume defects until the review finds none. Dense, confident code is the prime suspect: density earns scrutiny proportional to the claims it packs, and a clean-reading page is unproven, not clean.
- Verification precedes severity: every claim proves against the real domain — a geometry invariant, a schema contract, a package's actual API — and current disk at the positive-claim bar, the current file re-opened at the cited anchor, never prose, naming, comments, or a stale review snapshot.
- A claimed absence proves the member missing with content a file assembles through composed constants or interpolation traced through the composition — absence of the verbatim spelling at one site is not absence, and a false absence claim steers every rebuild into the inferior spelling the owning catalog rejects.
- A claimed presence — a parameter list, field mapping, return shape, or cross-file matching-rows assertion — proves its quoted shape on disk at every named site, a finding quoting a shape the file does not contain void; a removal or desynchronization claim verifies the declaration and every constructor site, since a declared and constructed case cannot be reported removed.
- Demanded fixes verify at the same bar: every member a demanded fix names — a replacement spelling, a compensating or unregistration operation, a stacking extension — proves existence, public accessibility, non-deprecation, and a declared type, return, and rail shape admitting the demanded use, and a demanded routing proves the target owner's declared input types admit the routed value.
- A demand naming a phantom, internal, or deprecated member is void; where the host ships no public inverse, the declarative or structural form is the demanded fix, never compensation through a phantom member; a demanded form the surface's own enforcing gate refutes — a rewrite inverting the owning gate script's verified behavior, a fix the shipped validator rejects — is void at the same bar.
- A shape appearing only inside a declared forbidden-form comment or rejected-form example is documentation of the ban, never the live defect.
- Settled corpus law outranks reviewer intuition: a finding contradicting a contract the owning page rules — a factory's declared budget parameters, a ruled composition form, a seam's admission placement, a diagram template's exclusions — verifies against that page's stated contract before emitting, and re-litigating a ruled design is a false positive, not caution.
- Folder, branch, cross-libs, and `tests/` estate and language-tree `RULINGS.md` registries sit at the settled tier: a finding re-litigating a ruling row is void with the row as the refutation; a diff genuinely violating a ruling demands the card route — an IDEA at concept grain or a TASK at landing grain, never an inline workaround — and a diff whose stronger form a ruling anticipates receives the ruling-aligned deeper demand, a fix landing below the ruled bar unfinished.
- Pinned-newest provider surfaces are corpus law: a released-library semantics claim — a member's return type, a pool's self-heal mechanics, a roster's existence — verifies against the owning doctrine page before flagging, and a provider-behavior claim — including what a member's internals strip, drop, retain, or default — verifies against the installed distribution's actual code path, never assumption.
- Standing hunts run as active searches against every diff, each presuming the gap until the pass proves otherwise — a diff none of them examined is unreviewed, not clean; the hunt rosters ride the structured rules in `config.json`, and every scoped rule there is a standing search, never a passive filter.
- A reviewer reports and demands, never edits. Every finding carries the file, the anchor, the defect, and the stronger form demanded — precise enough that a fixer lands the repair without re-deriving the analysis; a finding row carrying an id and severity but no claim, target, or anchor is void, never a placeholder, and the anchor names the file owning the flagged construct — a construct living elsewhere routes the finding to its owner, since an edit at a non-owning page cannot resolve the defect.
- A finding's demanded fix names the strongest form the owning doctrine admits, never the local patch, and spells its mechanism in the owning page's rail idiom — a demanded raw exception, clamp, or ad-hoc guard against a page whose concern rides a monadic rail is the shallow demand fixers transcribe, so the demand names the typed fault case, admission fold, or policy row on the existing rail instead.
- Shallow-demand shapes owing the deeper form: a guard bolted onto a fragment where the owning fence dissolves the fragment into its one fail-fast pipeline; a demanded mechanism the platform itself refutes — a drain pattern that still deadlocks under backpressure, a call the target platform does not ship — where the demand must name the platform-true form; a blanket replacement where the defect splits at an admission boundary, the interior form correct by construction and repair owed only at the foreign edge. Discriminator: where the owning page rules the local shape, the local patch IS the strongest form and a deeper-collapse demand re-litigates settled law.
- Cross-surface coupling is standing duty: `docs/laws/topology.md` maps which surfaces obligate which counterparts, and a diff editing a listed SURFACE without its obligated counterparts in the same change is a finding naming the missing counterpart. `docs/laws/scars.md` and `docs/laws/patterns.md` laws are standing review duty.
- Suppressions and gate bypasses are the finding, never the mechanics the gates already own: a true positive is architecture pressure to fix the shape, a false positive is rule pressure to refine the rule, and a suppression directive is neither. Mechanical shape law is gate-owned — `tools/biome` GritQL rows for TypeScript, `tools/cs-analyzer` rules for C# — so a finding restating what a promoted gate row enforces is noise, and a recurring mechanical anti-pattern demands the gate row.
- Judge composition idiomatically: an interface earns its existence through dispatch or substitution, and generated or source-gen surfaces run at intended power — decorative abstraction is a finding.
- A fence member whose body is a placeholder comment (`=> /* ... */ ;` or an empty braced body carrying only prose) is an illusory implementation — reject it before deeper review, because the surrounding prose asserts capability no route materializes. A resource-release claim in prose or comments — bracket release, abort-on-every-exit, dispose-on-fault — binds to a visible call in the shown body, and a design upgrading auto-cleanup to durable resume deletes the release claim in the same edit.
- Sweep every fence for local compilability before content review — planning fences have no compiler, so these fictions survive fluent prose: a `ref struct` operand captured by a lambda or riding a generic carrier, an identifier neither declared in scope nor owned by the page, a value returned from a `void` member, a brace-only body where a return type demands a value, a type name written as an invocation, a generated-owner row whose positional argument count drifts from its declared constructor arity, a railed factory result — a `Result`- or rail-returning entry — bound into a bare-typed slot with no flatten, a payload passed outside the factory's declared admitted union, a bare `guard(...)` arm or `guard(...).Map(...)` where the rail projection must precede any combinator, a rail-valued lambda relying on implicit `Error`-to-`Validation` widening outside a target-typed position, a traversal or fold trait member spelled on a bare array or `FrozenSet` with no `toSeq(...)` lift, a one-parameter arm on a state-threaded `[Union]` `Switch` or a two-parameter arm on a state-threaded `[SmartEnum]` one — union arms take `(state, case)`, smart-enum arms the state alone — a `Switch` whose arms return sibling case types with no union-base cast anchoring the first arm (CS0411), a `[UseDelegateFromConstructor]` member carrying an authored body where the generator owns the implementation from the constructor-supplied delegate, and a derivation from a registry row — a fault-band offset, a parity slot, a wire key — whose registry declaration does not exist.
- A closed union whose every case carries one identically-typed field re-projected by a total switch is operand restatement — demand the shared value as the consuming entrypoint's argument with cases keeping only per-occurrence policy; two cases byte-identical in payload and behavior, differing only in name, collapse to one case whose discriminant derives from the op's trait row.
- A shared mechanism homes at the lowest stratum every consumer references — a wrong-high home is the causal engine of per-folder twins, and a folder-local re-declaration of a lower-stratum owner's concept demands composition of that owner as an instance, per-folder fact unions the one legitimate plurality. Inversely, a collapse demand states what the merge loses: where the plural form carries a guarantee — a per-folder closed roster's compile-time break, a dependency boundary keeping host SDKs above their stratum, a deliberate isolation co-location — the plurality is lawful and the unifying discriminant states at a durable owner, `RULINGS.md` the home when no page owns it.
- Attack fold accumulators: a seed starting completeness flags true fabricates a computed receipt over an empty input set — demand an explicit empty-set rail or false-seeded flags, with one sibling fold railing empty while its neighbours do not as the tell; a fact stream folded into a name-keyed bag silently drops all but one entry under a repeated key — set-valued findings emit as one typed list value under one name; a subset test over a requirement row (`need <= available`) reads an empty requirement as vacuously satisfied, silently inverting a disabled row into always-enabled — demand the explicit empty-row short-circuit.
- A safety guarantee a shared rail claims — fence, lock, guarded predicate, tenant guard — is consumed structurally by the rail body from the case's data row; a per-case executable delegate whose body carries the guarantee makes the claim illusory and unreviewable.
- Prose signatures byte-match their fence declarations: an Entry/Auto row whose parameter list, rail, or return drifts from the fence is a wrong contract a downstream composer builds against, and a fence signature edit ripples its prose rows in the same diff.
- In a closed dispatch family folding one shared request shape, every column is consumed or loudly refused by every arm — an axis some arms read and others silently ignore converts an unrepresentable check into a silent pass. Trace every declared policy or vocabulary column to the executable arm its card claims: a column consumed only by a cache key, receipt, or log annotates rather than governs — demand the governing arm or the demotion. An arm that cannot honor a policy field refuses the combination loudly before provider work — a silently weakened or partially applied policy is the finding.

## [02]-[SEVERITY]

Grade across the full scale. High marks a correctness, contract, or architecture breach a consumer inherits; medium marks a weak form with a demanded stronger one; low marks residue worth draining. A review where every finding lands at one severity has averaged, not graded — and a pass that finds nothing after genuine attack states that as its verdict, never padded with manufactured findings.

## [03]-[DO_NOT_FLAG]

Deliberate house shapes that violate generic best practice — flagging them is a false positive:

- Source descriptors retained beside a derived projection are not ignored, so an omission finding proves absence from both owners.
- A modulo accessor is not an out-of-range access, and an option-shaped lookup is not a throwing access.
- An optional egress that maps an empty aggregate to `None` exposes absence rather than concrete closure evidence.
- Author-declared census fields are not native read-back counters, so a host-completion finding cites the actual read surface.
- Private planning or search evidence is not output-affecting identity unless the frozen egress carries it.
- An in-process callback owes owner-derived coverage rather than host-completion evidence when its charter exposes no host boundary.
- Branches already inhabiting one typed rail need no carrier repair.
- A duplicate-validation finding cites a second declaration or admission call rather than an imagined sibling site.
- A consistency-check demand between a declared shape and a value the owner computes from that same shape is void — a computed projection cannot desynchronize from its inputs; the demand is real only against an independently stored field.
- A completeness or restoration demand against a registry or research row deliberately BLOCKED on an upstream producer is void — the blocked row is the correct fail-closed form, and the demand routes to the producer owner the row names.
- Current-state claims trace composed calls, derived projections, internal provider operations, and receipt or canonical-egress consumption before flagging; a declaration is not a second call site, a value proven on that trace is not unused, and a path already entering the named admission owner is not missing the check.
- Demanded mechanisms prove semantic compatibility: quantities share dimensions, the target owner carries the needed policy rather than adjacent capability alone, leveraged algorithms carry acceptance and fallback law, and fixed ceilings or invariants exist in owner or provider law rather than being invented.
- Planning registries relate only as their charters declare; concept-to-task derivation is not identity or status mirroring, and design-corpus fences owe transcription-complete code but no executable test.
- Provider and algebra claims verify semantics: count-taking ranges yield the requested count, projecting a vector onto a basis perpendicular to its parallel or antiparallel direction yields zero, and an internal provider operation satisfies the claimed setup step.
- An admitted lower bound refutes a counterexample the complete owner roster cannot cross.
- Algebraically equivalent factorings are settled current shapes rather than arithmetic defects.
- Concept-page index labels are ordinals rather than same-page links, and a link demand is valid only in a router file class whose page grammar authorizes routing.
- A declaration migration demand moves every direct constructor and consumer in the same change, so a declaration-only factory repair is incomplete.
- A local codec never duplicates a canonical-byte owner, whose case family extends before the consumer routes.
- Recursive execution expansion deletes only after the published trace retains every executable case, structural locus, and repetition identity.
- A predecessor dependency deletes only after the owning atom carries the intrinsic start, sweep, or equivalent evidence the consumer needs.
- Equal row shape, labels, formulas, codecs, current mappings, or a shared type NAME across independent packages are not duplicate law without one existing winner preserving semantics, policy, precedence, lifetime, evidence, and consumers; a declared package or stratum boundary admitting the peers only through a ruled seam refutes the merge outright, required ABI spellings stay on both sides, and a replacement spanning untouched ownership or lifetime concerns exceeds the changed defect.
- A package traversal lacking the owner's deterministic connected walk is not approved replacement leverage.
- Both sides of an external ABI retain the shared operation spelling required by that boundary.
- Payloads with different motion or effect semantics remain distinct even when their carriers look alike.
- Gate failures confined to pre-existing untouched lines are not findings against the reviewed diff and authorize no collateral edits.
- C# `Arr<T>` is a value carrier that cannot hold a null collection reference.
- LanguageExt `Seq<T>.Head` and `.Last` are `Option<T>` lookups rather than throwing empty-sequence accesses.
- Positive relational admission (`value is >= lower and <= upper`) rejects `double.NaN` because both comparisons are false, while negative rejection (`value < lower || value > upper`) requires an explicit finiteness fold.
- Refuted standing claims, banned verbatim at every severity — the named page read precedes any py3.15 syntax-validity or pinned-provider severity: "frozendict is not importable from builtins" (`from builtins import frozendict` is the legislated table spelling, `docs/stacks/python/language.md` [FROZENDICT_TABLE_SITE]); "start_soon returns None" (`start_soon -> TaskHandle[T]`, `handle.return_value` read after group close, `docs/stacks/python/concurrency.md` [CHILD_CARRIER]); "except A, B: is invalid syntax" (paren-less multi-exception is py3.14+ grammar and the ruff-format canonical form the repo gate emits).
- A transitive central-manifest row carrying its `Rides <puller>` comment is proven indirect custody, never an orphan or unused-dependency finding.
- A missing-registration claim emitted without sweeping every README section cluster is void — a package registers once at its tier-correct section, and the single-cluster sweep is the false-missing engine that manufactures double rows.
- Re-litigating a `RULINGS.md` row — re-admitting its rejected package, folding its ruled-plural surface, re-homing its ruled owner, re-adding its retired structure — is a false positive at every severity; the row is the refutation.
- Aggressive API breaks with every call site updated in the same change: the sanctioned rename path.
- Dense single-expression bodies and heavy polymorphic dispatch: the bar, not obfuscation.
- Absent defensive guards inside domain logic: admission-once boundaries, not missing error handling.
