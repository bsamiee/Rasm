# [TYPESCRIPT_PRINCIPLES]

Rules a package-by-package rebuild of `libs/typescript` and its consumers follows.

1. Each package holds what it does and builds on whole layers beneath: host plumbing once (the MCP transport and runtime, the UXP runtime, entries and link, the Apple-event transport and the helper spawn, the Cloudflare and Node hosts, one SQL engine per dialect, pdf.js, harfbuzzjs), generic parts beneath, compositions above (Atelier, the portfolio, argus, infra). App content sits in the composition: env names and flag text, the OpenAI Sites contract and Cloudflare Access paths, `app.tenant`, `_cf_*`, tuned timeouts, `forcePathStyle`, a vendor's install path and English stdout match, tool prose and snake_case tool tags, a script dialect
2. `Schema.fieldsAssign` over a `Schema.Class` draws TS2345, and a class variant derives through `mapFields(Struct.assign(..))`
3. Host replies spelling absence as `null` or `''` decode both in one union
4. Host values decode through a schema at the read, stating every runtime form the host returns where its typings state fewer. `Entry` reaches `adobe:uxp` as a type alone, and a UXP entry decodes by its `isEntry: true` field with a `url` string or `URL`.
5. URI segments encode through `SchemaGetter.encodeUriComponent` inside their `Schema.TemplateLiteralParser`, URLs build through `Url.setUrlParams` over `UrlParams.fromInput`, and SQL identifiers quote through the engine
6. Reconcile keeps a rename identity on the reconciled object (`COMMENT ON`, SQLite schema text), refuses each drop or retype no owning type declares through a `Finding`, and reads live facts from the engine catalog (`pragma_table_list`, `sqlite_sequence`) in place of text matches on live DDL
7. Packages declare their `Schema.TaggedError` only for failures no host error (`PlatformError`, `HttpClientError`, `SqlError`) or `Unmatched` states. `Unmatched` is the lookup refusal, `Cause.IllegalArgumentError` the arity or kind refusal, and a contract error is `Schema.Union([Unmatched, <Package>Error])`
8. Swift wire stays byte-identical in every key, `_tag`, case and enum spelling the readers decode (`automation/{contract,apple-events,applications,fonts}.ts`, `search/unmatched.ts`, `atelier/status.ts`), every field the helper sends is declared (a `Record(String, Json)` declares none), and `Unmatched` keeps the `single <subject>` spelling the Swift writer sends

## [01]-[PACKAGE_USE]

Code reaches each catalog package through its members at the version `pnpm-lock.yaml` pins, and hand code stands only where a family names it: 9. effect and effect/ai: the host-header allow-list (`McpServer` checks `Origin` alone), the MCP protocol list (`McpProtocol` exports no aggregate), the Manifest decode (UXP types none) and the `{?query}` resource template (`McpServer`'s private `compileUriTemplate` builds path parameters alone) stay by hand. `McpServer.registerResource` routes and completes path templates, `McpSchema.optional` takes `undefined`, and a tool's annotations read through `Context.get(annotations, Tool.Readonly)` 10. @effect/sql, @effect/platform-node, cloudflare: `sql.onDialect` picks one engine with its `mysql`, `mssql` and `clickhouse` arms failing, `HttpServerResponse.raw` passes a partial-content `Response` through with its mime, and `env` from `cloudflare:workers` builds once 11. pdfjs-dist, harfbuzzjs, fontkit: `PDFViewerOptions` takes `abortSignal` (read at runtime, untyped), `EventBus.on` takes `{ signal }`, and consumers read the returned `PDFViewer` and `EventBus` members. By hand: `0xff_ff` and the name-ID table (harfbuzzjs exports neither), the CFF decode (fontkit types none) 12. InDesign: the `do script` Apple event sends `{ direct: { _tag: 'file', url }, language: 'uxpscript', 'with arguments': [message] }`
