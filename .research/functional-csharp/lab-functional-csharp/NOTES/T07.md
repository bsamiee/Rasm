## (b) Dropped or corrected statements

- No existing artifact exists for this lane under `.scratch/thinktecture/`.
- wiki:ToReadOnlyCollection says the methods "save copying a collection". Refined: the wrapper delegates enumeration, so a deferred projection re-runs per enumeration and `Count` is the caller's number, never counted.
- wiki:SingleItem shows `SingleItem.Dictionary`, `Lookup`, `Set` without the comparer parameter and without `TKey : notnull` on `Lookup`. The decompiled signatures carry both.
- decomp XML doc on `ToReadOnlyCollection(count)` documents `ArgumentException` for a negative count. The thrown type is `ArgumentOutOfRangeException` (probe). The doc names the derived type.
- The ledger expected the null `items` path of the selector overload to report `source`. Probe confirms `source` (from `Enumerable.Select`).
- wiki:TrimOrNullify hook sample has no key comparer attributes. Under the repo analyzers `TTRESG048` and `TTRESG103` are errors, so the doc block declares `KeyMemberEqualityComparer` and `KeyMemberComparer`.
- Planned anti-pattern "default equality of a string value object": the default without the attribute is `OrdinalIgnoreCase` (probe), and the attribute makes it explicit. Rewritten to name the declared accessor.
