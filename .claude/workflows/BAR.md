# [BAR]

Code a workflow run writes in any language meets every line, judged hunk by hunk in `git diff` against the run's base.

## [01]-[CODE]

- Capability: the domain's full capability under advanced use in the fewest names, as general logic any future app, tool or plugin composes
- Reading: agents read code whole with its consumers, each package from source at its pinned release, and recorded findings as facts to act on
- Recorded findings: `RUST.md`, `TYPESCRIPT.md`, `.artifacts/workflows/` and `docs/research`
- Defects: fixed in the same pass at every layer holding them
- Reduction: a struct, type, interface, enum, error variant, constant, string literal set or validation exists where a caller acts on it differently
- Reduction: every other one folds into fewer objects holding their operations
- Derivation: values derive from the type, member, host query or standard that owns them, sizes, steps, limits and names included
- Derivation: related quantities sit in one algebraic relation solvable for any of them, and one parameterized item serves every variant
- Packages: each dependency's full capability through its own members, and hand logic a package states is deleted
- Packages: the newest, strongest package joins where it owns a fact code hand-writes
- Release: each project's newest target release in its forms (Python 3.15 and its PEPs, TypeScript 7, Effect 4, Rust 2024, Swift 6.4, .NET 10)
- Visibility: public names are what a consumer composes, every other member is private in its language's form
- Shape: flat control flow, no wrapper, alias, forwarding layer, single-use helper or stringly form, and agent-facing messages built from their values
- Architecture: a concept owns its file, a folder groups concepts, and a module made to break an import cycle marks a wrong boundary to rebuild
- Architecture: no mini file, single-file folder or coined name
- Both ends: present code, names and consumers hold no authority and couple nothing
- Both ends: a library and its consumers are rebuilt together, each consumer calling it directly, nothing kept for compatibility
- Public capability: public declarations, parameters and cases no consumer reads stay as capability, rebuilt where weak

## [02]-[HUNKS]

- Reductions delete declarations, cases, parameters or lines whose fact an owner, one parameterized form or a package member then states
- Shuffles move, rename or renest code, or swap a form for one of equal size, deleting no declaration and giving no concept its own file
- Shuffles finish into a reduction or revert
- Regressions drop used behavior, restate a fact, accept a state base refused, lose a failure cause, join concepts in one file or inline a named value
- Regressions restore
- Growth stands where it names the capability that needs it, or the hidden failure or invalid state that gained its case
- Hunks name the fact they remove, the behavior they add or fix, the concept they give its own file or the coined name they replace, else revert
- Small wins and small regressions count the same as large ones
- Consumers of each changed declaration move to the new form in the same pass, holding no adapter to the old shape

## [03]-[AGENTS]

- Briefs state the goal, its inputs and `BAR.md`, with no pass number, narrowed scope, validation language or negative framing
- Adversaries read the diff against base and the files whole, with no earlier agent's report, each pass at equal depth and aggression
- Later passes lean to collapsing existing types, structs, enums, classes, models, constants, strings and functions into stronger logic
- Skills, rules, names and messages change by replacing or rewriting the line that owns a fact, and text appended to an existing line is a regression
- Reports reach the owner as results and decisions, and a finding is acted on or left unsaid
