# [LIBS_RULINGS]

`libs/` rulings settle estate-spanning decisions.

## [01]-[PACKAGES]

- Package admission runs the bounded-context test — own nouns, own invariants, and a published boundary an unrelated application adopts alone; anything extending a settled vocabulary lands as a row, case, adapter, page, or sub-domain on its owner, and `ARCHITECTURE.md` `[12]-[ADMISSION]` owns the ladder. Host names, provider names, verbs, and size-driven splits name no bounded context, so a package minted on one pushes onto every consumer the fold its owner withholds.
- Host integration lands as one host-boundary package beside descriptor rows and cases on the domain owners its demands prove — a domain package naming a host couples every consumer of that domain to that host, and a per-host domain package forks the concept the host merely reveals. Generalization pressure arrives with each new host: its nuances widen the owners already holding the concept, and only a concept exclusive to that host earns a bounded context, named for the concept.
- Branch admission answers reach alone — a target runtime no existing branch reaches earns a branch, and a host scripted in a branch's own language is already reached. Ecosystem preference for a capability an existing branch reaches lands as a package in that branch; minting a branch for it splits one design language across two toolchains and manufactures a contract for every shape that then crosses.
- Cross-branch names align because the concept is one, spelled in each branch's casing law — a name mirrored into a peer for structural symmetry forks two concepts under one spelling, and a genuinely distinct concept keeps a distinct name. Roster symmetry across branch trees is never the goal, so a branch gains no package to match a peer's shape.
- Every shape crossing a branch boundary carries a `tests/contracts/MANIFEST.md` entry — convention alignment without one is coincidence that forks on first edit, never interop, and a cross-branch flow claimed on naming and shape parity alone has no conformance proof behind the claim.

## [02]-[SHAPE]

- Cross-language contracts split into two classes — every branch mints an INFRASTRUCTURE contract from its own inputs with corpus parity the proof, one producer named by domain capability emits a DOMAIN contract; a language-privileged producer for an infrastructure contract makes a single-language app undeployable, and a second domain producer forks the semantic model.
- Infrastructure planes are category-general — storage, asset pipelines, artifact receipts, landings, transport, serving, and instrumentation take their shape from the category algebra, never from the first consumer that occasioned them; the occasioning domain enters as a ROW (vocabulary member plus policy values) exactly like every later domain, one spine and one entrypoint serving all, and the admission proof is the next domain's diff — one row, every consumer untouched. A domain noun inside the plane's own shape — an asset pipeline that IS textures, a landing that IS one product family — seats the first consumer as the owner and forces the second to fork or re-mint the plane; domain coupling stays legal at the domain tier alone.
- Branch-interior wires mint no `tests/contracts/MANIFEST.md` entry — the photo→PBR inference wire stays C#-interior, `Rasm.Materials` specifying the stages and `Rasm.Compute` executing them, the `[WIRE]` pair at both folder `[03]-[SEAMS]` maps IS the complete registration; a corpus-entry sweep reading its proto-shaped stage documents as a crossing manufactures the interop `[07]-[CROSS_LANGUAGE_WIRE]` reserves for shapes that leave a runtime. Reopens when a peer branch consumes a stage shape.
- Backend contract composition is per-branch — each branch composes its contract from its own framework artifacts, mints its own generation, and deploys with no peer present; the merge is app-root and deterministic by artifact key; a shared implementation package or one privileged minter re-imposes the prerequisite the split exists to remove.
- Consumption axis roster homes at Tier-0 and spells per branch — `ARCHITECTURE.md` `[10]-[CONSUMPTION_MODEL]` owns the axis set and each axis's form, a closed axis fixing its vocabulary there and an open axis fixing only the descriptor shape its supplying branch fills, with `tests/contracts/` `CONSUMPTION_PROFILE` proving parity; a package-local axis fork silently reintroduces the assumed-consumer defect the roster exists to foreclose, and enumerating an open axis's instances at Tier-0 re-anchors the roster to whatever instances exist today.
- Branch prose states its own domain and never a peer's ceiling — "production authority stays with the peer", "offline study evidence" as a standing rank, and "the peer owns the real one" each demote an estate `ARCHITECTURE.md` `[06]-[PER_LANGUAGE_ROLES]` declares independently adoptable, and no contract backs the demotion; a graduation rail carries evidence a consumer asked for, so the honest form names what crosses and leaves substrate, benchmark, and policy selection to whoever reads the receipt. Host-freedom and mutation limits stay legitimate — they bound this branch, not a peer's rank.
- PostgreSQL extension rosters stay branch-owned deployment state — the C# and typescript rosters name different engine families, share no consumer, and carry no seam edge, so neither is authoritative and no corpus entry defines the set; a parity demand across them, a unioned installable set, or one branch's preload gate read against a peer-derived image each manufacture the cross-language meaning `ARCHITECTURE.md` `[03]-[UNIVERSAL_VS_CAPTURE]` withholds until a manifest entry lands. Capability ROW SHAPE stays infrastructure where the backend contract carries it; the roster filling it never does. Reopens when one cluster serves both branches' contributions.
- Backend artifact dependency validation homes at each branch's projection funnel, never at its sort — artifact key order is the whole wire order, so a topological or depth rank inside the stream mints a second generation from one artifact set; closure and acyclicity are invariants the one funnel every mint path reaches proves, and a validation bolted to an ordering function leaves every path that skips that function unproved.
- Library tiers stay app-neutral — instrumentation binds the API surface only, and no exporter, SDK wiring, correlation/tenant/host envelope, or ambient sink enters below the composition root; the composing app alone laces cross-cutting evidence — an app-bound library tier couples every consumer to one composition and manufactures per-folder twins of the app's lacing.
- Columnar-lake query ends ride one Flight plane in every runtime, carrying Flight SQL as a dialect layered on it rather than as the serving base — a per-runtime second query transport re-derives the lake's admission, auth, and typing at every end and drifts them independently; a runtime needing a new query capability extends the one plane's surface, never mints a sidecar transport.
- Retrieval fusion stays host-local per runtime — the C# store and the typescript data end each fold reciprocal-rank fusion in one database statement, and no cross-language fusion parity or projection seam exists; a ripple sweep seeing the two fusion owners side by side re-proposes the removed cross-runtime projection, the refuted fabrication; the row reopens only if retrieval federation stops being host-local.
- Reliability-indicator vocabulary is one cross-branch algebra spelled twice — the typescript core observe owner holds the reference form and the C# kernel capsule transcribes it, so an indicator case, breach polarity, burn row, severity, or panel kind lands in BOTH spellings beside every query fold and compile leg reading them; a branch-local case declares a target one runtime alerts on and the other cannot render. Series selection stays branch-local, each package naming its own mounted rows.
- Success share over one tag-partitioned counter is an indicator case, never a second counter carrying the numerator — an outcome, verdict, or disposition dimension already keys the good half, so a twin doubles the mounted series and strands its denominator on any emission edit; the two-counter shape survives for genuinely independent counters alone, and a level bounded on either polarity is one shape with a direction column rather than a second family.
- Telemetry domain segments name capability subjects and stay branch-declared — `ARCHITECTURE.md` `[08]-[OBSERVABILITY_CONFORMANCE]` fixes the grammar, the subject test, the carves, and the resolution gate, and each branch's conformance minter owns its own roster of segment beside admitted subject. Runtimes serving one subject therefore share the segment under `service.name` separation and both claimants spell that subject byte-identical, while a segment minted per emitter forks the series a board joins across.
- Telemetry conformance proves through the corpus entry alone — `tests/contracts/` `TELEMETRY_CONVENTION` binds the three mints and parity across them IS the proof, while transcription stays how each branch spells the rows into its own composition. Split SDK maturity earns the absent shared library and never an absent entry, so a conformance claim resting on naming and shape parity carries no gate and forks at the first branch-local edit.
- OTLP is the one metrics-store ingest door and remote-write is declined estate-wide — every store row ingests one wire, which is what keeps the row family swappable and the single-ingress law meaningful; a remote-write leg beside it forks the ingest contract per store and strands the UTF-8 translation pin the dotted-name grammar rides.
- Every analytics-residence family answers ONE capability floor and extends it with what only its own plane decides — `fits` the sentence a reader selects the row on, `ingest` the writer that fills it, `tenancy` the isolation mechanism, `retain` the retention mechanism, `degrade` the honest clause naming what the row gives up, and `cap` stated permanently false so a later pass cannot add the cardinality budget these planes exist to refuse. Crossing two families then reads different VALUES under one column set: a deploy plane adds its chart, door, and signal-roster columns, a write plane its layout and tuning columns, a read plane its relation and accessor columns, a provisioning plane its dialect tokens and statement emitter. No branch's extension obliges a peer, because a plane answering a coordinate it decides nothing about answers it by guess, and a family carrying fewer than the floor drops a coordinate its own callers then hardcode. Which residences a branch ROWS is its own vocabulary; the floor binds the columns, never the roster.
- Generated-schema wires whose two ends pin divergent generations refuse at the CONSUMER and never re-encode at the producer — a producer hand-mapping a retired field onto the live one mints anchors its own IR never held, and proto3 hides the divergence by filing a retired field into the unknown set rather than raising, so a plane parses clean while its whole extension space vanishes. Consuming gates name that signature as their own refusal reason, both `.api` catalogs record the field numbers at each end, and the refusal retires only when a released producer pin carries the live generation.
- Every branch shipping a diagnostic archive carries a BACKEND-FREE read plane over its own instruments, composing no exporter, collector, or store — an archive is pulled exactly when the egress is what failed, so a capture reaching its measurements only through the wire answers nothing about that failure. Reading never emits, so the plane is no second truth beside the receipt fan, and an instrument the process never measured reads UNMEASURED rather than zero because a fabricated zero and a dead producer are the two states an operator needs separated — which a pulled reader answers only by publishing a measurement SEQUENCE, absence being unspellable in a scalar one. Arming is a composition policy value, and a plane ACCUMULATING its own cells carries a distinct-series ceiling folding overflow onto the specification's own marker, while one projecting a store the view engine already bounds takes none.
- Unbounded append retry admits only behind content-keyed idempotence AND over a rail whose faults are transient by TYPE — a plane that never sheds retries forever, retrying a bare INSERT double-writes the first time a driver loses an acknowledgement it already committed, and a permanent fault sharing that rail wedges every later row behind one the plane can never accept, so the key and the rail split are both preconditions rather than later hardenings. Landings account for every offered row and report accepted beside matched-duplicate as separate halves, since one merged tally claims zero redelivery and zero redelivery is indistinguishable from a wedged retry re-offering one window forever; counters, log lines, and metric egress fire from the accepted half alone, because a replayed batch projecting twice doubles the series the plane exists to keep honest, and the refused attempts carry their own series because a drain sitting on a dead backend otherwise reads exactly like a quiet one.
- Never-shedding planes close by FLUSHING, never by interruption — a graceful stop signals the intake done and lets the consumer finish what producers already offered, where cancelling that consumer at scope teardown abandons both the window in flight and everything queued behind it, which is the largest single loss such a plane can take and the one its own back-pressure law never covers. Whatever a refusing backend or a bounded shutdown still leaves unlanded stays readable as a roster of ROWS settled by identity, so a re-armed composition still owes what its prior session never landed and a caller re-offers or persists them; a tally names nothing to re-offer, and clearing the slot on the first success sheds the debt silently.
- Evidence planes order and settle on their own stamped coordinate, never on a storage engine's write clock or generated sequence — a row landing late under a dead backend carries a write time arbitrarily past the instant its fact occurred, so a settlement window, retention cutoff, or signal-to-evidence join predicating on that clock misfiles it with no later query able to recover the truth. That stamp lifts into its own indexed column beside the opaque payload, since a coordinate every reader predicates on is no longer payload.
- Exact-decimal claims start at the ACCUMULATOR, never at the multiply — a settlement fold summing into a float or a 53-bit integer loses the value before the decimal carrier sees it, and every language's widening constructor accepts that rounded input without complaint, so the preimage folds in an arbitrary-precision integral type and rounds exactly once at the terminal.
- Pulled levels bind to their OWNER's lifetime, never to a name alone — a registered read publishes while its owner holds the bound and stops when that owner retires, so a dead owner's last value never freezes into a level no collection tells from a live one, and one name carries every live registration rather than a slot the newest overwrites, since two bounded owners under one measure are two series last-writer-wins deletes. Each read fences alone, because one raise costs every sibling reading in that collection cycle, and a read that cannot answer publishes NOTHING — a fabricated zero and a dead producer are the two states the pulled plane separates. Pushed cells stay the shape for a call-site producer, so a saturation indicator naming a cell-fed level declares a target nothing retracts.
- Columnar DDL plants at the tier that installs the residence and whose writer fills the relation — the planter runs before the first write, leads the sort key with tenant, and stays reachable in every topology the spec admits, so an estate-wide single-emitter claim fails at the first stack running no peer runtime. Readers transcribe the planter's spelling under the topology residence-DDL coupling, and column-type vocabularies stay branch-local until a manifest entry defines a correspondence.
- Reliability-indicator rendering rides the deploy tier's realized backend projection, never a column on the objective — the kernel family stays backend-neutral, the rate window crosses on the burn row, and an objective naming a residence is a second selection the realized one contradicts silently. Every residence family answers each board wire form through one dialect row or declares the gap on `degrade`, so a residence the one query owner cannot address is a fork, never a second query path.
- Append-only log planes own truth and every derived plane carries zero authority — folds, snapshots, traces, cell tables, overlays, and actor configurations accelerate reads and drop at warm-up cost; a shape crossing planes names its truth plane, its rebuild route, and the retention floor below which rebuild fails. Reading a projection as authority turns a dropped accelerator into loss and opens the write-back path folding drift into the log; an owner with no log declares itself ephemeral.
