## Corrections with evidence

- CORRECTION: `RunSafe(EnvIO)` does not capture cancellation. With `EnvIO.New(token: new CancellationToken(canceled: true))` and `IO.liftAsync(env => FetchAsync(6, env.Token))`, `RunSafe(env)` threw `System.Threading.Tasks.TaskCanceledException at LanguageExt.IO`1.Run(EnvIO)` out of the process. `Try.lift(() => io.Run(env)).Run()` returns `Fail(cancelled)` (`Errors.Cancelled`). This extends the API document line "IO.lift rethrows cancellation during execution": the safe runner rethrows it too.
- CORRECTION: `IO.fail<A>(error).Finally(x)` never runs `x`. Decompile of `LanguageExt.DSL.IOFail<A>`: `public override IO<A> Finally<X>(K<IO, X> @finally) => this`. The same node overrides `Catch` to `Fail(Value).As()`, which works. `IO.lift(Func<Fin<A>>)` that fails at run time runs the finalizer (`closed.Value == 1`). The doc attaches `Finally` to the deferred failure.
- `Try.lift(io.Run).Run()` over `IO.fail(new Unavailable())` returns the original `Expected` (`HasCode(503)` is true): the thrown `ErrorException` unwraps back to its `Error`.
- `LanguageExt.Sys.Test.Runtime` has no in-memory file system. Decompile: `Has<Eff<Runtime>, FileIO>.Ask => asks(rt => new Test.Implementations.FileIO(rt.Env.RootPath))`, `Runtime : IDisposable`, `Dispose() => Directory.Delete(Env.RootPath, recursive: true)`. `File<RT>.writeAllText("/notes.txt", ...)` failed with `Read-only file system : '/notes.txt'`. `Path.Combine(test.Env.RootPath, "notes.txt")` round-trips `kept`. The lab holds the runtime in a `using` declaration.
- `MemoryConsole` enumeration yields written lines only. After `writeLine("hello")` then `readLine` (fed by `WriteKeyLine("reply")`), `toSeq(memory) == Seq("hello")` and `readLine` returns `reply`. F00 saw `["hello", "reply"]` because it echoed the line with a second `writeLine`.
- Schedule values observed through `Run()`: `spaced(1ms) | spaced(3ms)` yields `[1, 1, 1, 1]` (union takes the shorter delay), `&` yields `[3, 3, 3, 3]` (intersection takes the longer), `exponential(1ms) & maxDelay(4ms)` yields `[1, 2, 4, 4, 4]`, `spaced(1ms) | recurs(2) | repeat(2)` yields 4 delays, `exponential | recurs(3) | jitter()` yields 3. `Repeat(Schedule.recurs(2))` ran the effect 3 times (`ticks.Value == 3`). `Retry(spaced | recurs(5))` on an effect that fails twice ran 3 attempts.
- Buffer retention when every `Post` precedes `Reduce`: `Newest(2)` kept `[2, 3]` (sum 5), `Latest(0)` kept `[3]` (sum 3), `Unbounded` kept all (sum 6). With the reducer forked first, `Bounded(2)`, `Single`, and `Unbounded` all drained five posts (sum 15). `Single` and `Bounded` block `Post` when full, so the reducer must be forked before posting.
- `Source<A>.Fold(f, 0)` over a lifted observable of `1, 2, 3` then `Reduce` sums to 0: the fold emitted nothing, confirming the LAB-NOTES correction. `Reduce` yields 6.
- A pipeline `yieldAll(Seq(1, 2, 3)) | map(x => x * 2) | repeat(awaiting().Bind(x => IO<Unit>))` ends when the producer ends and the atom reads 12.
- Analyzer rulings met here: `VSTHRD200` requires the `Async` suffix on a `Task`-returning method (`FetchAsync`); `MA0167` rejects `Task.Delay(TimeSpan, token)` without a `TimeProvider`, `await Task.Yield()` then `token.ThrowIfCancellationRequested()` avoids it; `IDE0200` demands the method group `queue.Post` instead of `item => queue.Post(item)` inside `TraverseM`; `IDE0047` rejects the parentheses in `(a | b) | c` between schedules; `CA1822` requires `Query()` to read instance state (`Disposed`).
- The brief's ban on `IO<Fin<` in the doc text conflicts with declaring the `IO.lift<Fin<A>>` result as a local type. The doc maps it at once with `.Map(fin => fin.IsSucc)` so the declared type is `IO<bool>`.
