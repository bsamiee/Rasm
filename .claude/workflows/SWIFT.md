# [SWIFT_PRINCIPLES]

Rules a module-by-module rebuild of `libs/swift` and its consumers follows, each stated once as a rule about the code. Snippets are the target form; a cited line names the current code the form replaces.

1. Each module owns the host plumbing of its concern and builds on whole layers beneath: `Results` and `Encoding` hold host-free values, `JSONRPC` frames one envelope over lines a caller supplies, `CurrentProcess`, `Files`, `Processes`, `Applications` and `AppleEvents` each own one host surface (os and the responsibility SPI; FSEvents and the lock protocol; `Subprocess` and process termination; `NSWorkspace`, `NSRunningApplication`, the AX API, ScreenCaptureKit and the font catalog; Apple events and scripting definitions), and `tools/watch-apps`, `apps/macos/relay` and `apps/creative-cloud/atelier/macos` compose them. App content sits in the composition: the `/usr/bin/security` keychain protocol Relay's trust rule names, Claude Code's lock paths and backoff numbers, Adobe's bundle prefix, activation stems, sdef codes and `DjxM` script event, Atelier's request vocabulary with its walk predicate and PNG policy, watch-apps' notification subset.
   `Keychain/Keychain.swift` → `apps/macos/relay`; `AdobeAutomation/Request.swift:66-139`, `AdobeScripting.swift:24,41-45,54-57` → `apps/creative-cloud/atelier/macos`; `ApplicationStatus.swift:34-36` → a parameter of the composition
2. A framework type stands wherever it states the value: a caller supplies `SCScreenshotConfiguration` and receives `SCScreenshotOutput` whole; `NSRunningApplication.activationPolicy` is read as the host enum and its wire spelling is one `switch` in the encoder of the record that writes it; an exit read off the main run loop goes through `proc_pidinfo`, which `isTerminated` lags; a kqueue wait status decodes once into `TerminationStatus` and a `NOTE_EXIT_DETAIL` option set; a face is `CTFontDescriptorCopyAttributes` whole.
   `Installation.swift:175` `createsWindows` → `activationPolicy`; `Request.swift:51-57` → the encoder's `switch`; `Lifecycle.swift:160-161,221-224` raw `Int32` and a hand `TerminationStatus.init(waitStatus:)` → one decode; `AvailableFace.swift:29-38` five of 27 attributes → the whole dictionary
3. A host vocabulary derives from the host at the read: attribute and action names, settability, specifier forms and codes; a refusal has one owner.
   `Element.swift:10-11,92,96,284` lists and the `valued` whitelist → `AXUIElementCopyAttributeNames`, `AXUIElementIsAttributeSettable`; `Element.swift:246` and `ElementAction.swift:37` → one owner; `AppleEventValue.swift:9-53,165,199,264-277` `KeyForm`, `Ordinal` and the specifier build → `form*`, `kAE*`, `CreateObjSpecifier`
4. A failure carries the host cause as its payload (`Errno`, `AXError`, `CocoaError`, `DecodingError`, `SubprocessError`), rendered to text only where JSON is written; two outcomes are two `Result` values, never optional pairs or a `reason: String`; a forward-compatible decode catches `DecodingError.dataCorrupted` alone into an `unknown(String)` case; `Unmatched`'s ambiguous case keeps the wire's `subject: "single <subject>"` spelling.
   `case exited(Result<TerminationStatus, Errno>, report: Result<CrashReport, CrashReportFailure>?)` in place of `Lifecycle.swift:20` five optionals; `Lifecycle.swift:19` `failed(reason: String)`, `Element.swift:32` `error: AXError.RawValue`, `Paths.swift:6` `Result<Value?, any Error>`, `ProcessFailure.swift:11` `.io(any Error)` → typed payloads; `Lenient.swift:12,27` → one catch; `Request.swift:83` `Result { () async throws in }` → `Request.Failure`
5. Independent results accumulate through `AggregateError`, `combine(repeat each)` and `traverse`; the one timeout is `withTimeout` over `race`, and `CancellationError` is the cancelled case.
   `ProcessFailure.swift:18` `.deadline(.cancelled)` restating `CancellationError` → one case
6. A host callback becomes an `AsyncStream` through `makeStream(bufferingPolicy: .bufferingNewest(1))` with its release in `onTermination`; a blocking host call runs as a `@concurrent` function under `withTaskExecutorPreference(queue)`; an actor caches an in-flight `Task` and evicts it on failure; a wait that something wakes is `race` of a sleep against a `bufferingNewest(1)` stream; a value crossing isolation is `sending`.
   `let (wakes, wake) = AsyncStream.makeStream(of: Void.self, bufferingPolicy: .bufferingNewest(1)); await race(Task.sleep(for: delay), against: wakes.first { _ in true })` in place of `AccountStore.swift:300-308` a cancelled sleep task
7. Codable is synthesized with `CodingKeys` mapping host keys once; unknown fields survive through `JSONDocument<Known>`; `JSONValue` holds one numeric case and backs a `Decoder` so a line parses once and an encoder is built once; a tagged union encodes its `_tag` through one generic envelope; a hand `encode(to:)` stands only where a stored type has no `Codable` and the wire fixes its keys (the exit case over two `Result`s); a hex value has one codec in `Encoding`.
   `Element.swift:63-84`, `Message.swift:21-30,134-170`, `ScriptingDictionary.swift:31-33,54-56` hand encoders → synthesis; `Message.swift:38-50` `String(describing:)` and `Mirror` tags → declared tags; `Hex.swift:5`, `Keychain.swift:43`, `FourCharCode.swift:8-18` → one codec; `JSONRPCConnection.swift:137,155,176,187` double decode → one `JSONValue` parse; `:220` an encoder per send → one; `AppleEventValue.swift:105-113` a catch-all ladder → decode `JSONValue` and map
8. Process termination with its status is one public stream in `Processes` over kqueue `EVFILT_PROC` `NOTE_EXIT`, read by `Applications`; a parent-exit watch with no status keeps `DispatchSource.makeProcessSource`.
   `Lifecycle.swift:186-218` private wait → one public stream
9. Launch takes the facts a caller decides (`hides`, `arguments`, `environment`, `createsNewApplicationInstance`) and builds `OpenConfiguration` inside; the AX notifications an observer watches and the poll interval are parameters of the composition.
    `public func launch(_ installation: Installation, hiding: Bool = false, arguments: [String] = [], environment: [String: String] = [:], newInstance: Bool = false) async -> Result<NSRunningApplication, LaunchFailure>` in place of `Lifecycle.swift:76-91` overwriting the caller's configuration
10. The file watch keeps FSEvents' per-event flags and reads paths through `kFSEventStreamCreateFlagUseCFTypes`; the lock protocol keeps Claude Code's steps byte-compatible (non-recursive `mkdir` of `<file>.lock`, the stale mtime test, the mtime heartbeat, compromise on a changed mtime, remove on release, the `max(stale, 2s)` and update clamps, `realpath` canonical paths) while inode identity, mode, logging and the retry schedule are local; a backoff is a value of count, base, growth factor, cap and jitter, its numbers in the app that mirrors Claude Code.
    `Backoff(count: 6, base: .milliseconds(200), growth: 2, cap: .milliseconds(4000), jitter: 1..<2)` in place of `ClaudeCredentials.swift:257`; `FileWatch.swift:111` C paths → CF types
11. A CF read checks `CFGetTypeID` inside the one generic `value` read; an SPI with no public counterpart (`_AXUIElementGetWindow`, remote tokens, `responsibility_spawnattrs_setdisclaim`) is declared once, in the form the manage-repo skill's Swift reference states.
    `Element.swift:206-212,313`
12. CasePaths serve a projection a reader makes (`.is(\.exited)`, `[case: \.failure.unreadable]`), never an `errorUserInfo` a `switch` states; OrderedCollections stand where order is read; AsyncAlgorithms members sit in the module that composes streams; a product member stands wherever it states the value, and a product goes where the standard library or a framework states the member or nothing calls it.
    `Keychain.swift:29`, `LoginShell.swift:24`, `Lockfile.swift:99`, `Lifecycle.swift:66` → `switch`; `AppleEventValue.swift:4` unused import
13. `Xcode.xcconfig` `SWIFT_WARNINGS_AS_ERRORS_GROUPS` names the groups `Package.swift` names.
    `Xcode.xcconfig:34` lacks `ExplicitSendable`
14. The wire to TypeScript stays byte-identical in every key, `_tag`, case and enum spelling the readers decode (`@rasm/automation`, `@rasm/search`, Atelier's status read, `.claude/skills/watch-apps/SKILL.md`), and the encoding behind a spelling is free to change.
    `Message.swift:157-168` ↔ effect `src/rpc/RpcSerialization.ts:348-380`; `Lifecycle.swift:18-20` ↔ `applications.ts:17-20`; `AppleEventValue.swift:73-76` ↔ `apple-events.ts:15-32`
15. A test target stands where a behavior over the public surface earns it, as `<Module>Tests` under `tests/swift/libs/<category>/<Module>/` through `.testTarget(name:dependencies:path:)`.

## [01]-[FRAMEWORK_USE]

Each framework and package owns logic its members state, and code reaches it through the member cited by declared name in the macOS 27 SDK or the pinned checkout. What stays by hand is named per family with the type it is written over, and nothing else is.

16. AppKit and ApplicationServices: `NSWorkspace.shared.openApplication(at:configuration:)` with `OpenConfiguration` built from typed facts, `observe(\.runningApplications, options: [.initial, .new])` (accessory policy needs the filter `DidLaunchApplicationMessage` lacks), `urlsForApplications(withBundleIdentifier:)`; `AXObserverCreate` with a run-loop source, `AXUIElementCopyAttributeNames`, `AXUIElementCopyActionNames`, `AXUIElementCopyMultipleAttributeValues` keeping its `AXError`, `AXUIElementIsAttributeSettable`, `AXIsProcessTrustedWithOptions` under `kAXTrustedCheckOptionPrompt` through `@preconcurrency import ApplicationServices` as the one trust member.
    `Element.swift:37` `_ =` dropping the `AXError`; `WatchApps.swift:96-98` and `Atelier.swift:18` trust checks → one `Applications` member
17. ScreenCaptureKit and CoreText: `SCScreenshotManager` over the caller's `SCScreenshotConfiguration` (`dynamicRange`, `showsCursor`, `contentType`, `destinationRect`), every `SCScreenshotOutput` member returned (`sdrImage`, `hdrImage`, `fileURL`); `CTFontDescriptorCopyAttributes` for a face.
18. Foundation and Dispatch: `FileManager.enumerator(at:includingPropertiesForKeys:options:errorHandler:)`, `NotificationCenter.default.messages(of:for:)`, `NSMetadataQuery` for a name search, `NSAppleEventDescriptor.sendEvent(options:timeout:)`, `CreateObjSpecifier` and `CreateOffsetDescriptor`, `realpath` for canonical paths, `proc_pidinfo` for an exit read off the main run loop, `DispatchSerialQueue` as an actor executor, synthesized `Codable` over a plist read once. By hand: `withTimeout` over `race` (no timeout in `_Concurrency` or AsyncAlgorithms), `AggregateError` and `combine` (no `Result` aggregate in the standard library), the kqueue `EVFILT_PROC` wait for a non-child's exit status (`makeProcessSource` carries none), the lock protocol steps, a `JSONValue`-backed `Decoder`, a hex codec (no member encodes a byte sequence as hex).
    `CrashReport.swift:45-60` recursive walk → `enumerator`; `Installation.swift:9-16` `InfoFlag` → `Bool` through `CodingKeys`; `AppleEvent.swift:33-36` `AESendMessage` → `sendEvent(options:timeout:)`
19. Subprocess, AsyncAlgorithms, CasePaths, OrderedCollections: `Subprocess.run` with `Executable.path`, `Environment.custom`, `PlatformOptions.teardownSequence`, `SubprocessOutputSequence.strings(separatedBy:)`, `TerminationStatus`; `chain`, `merge`, `removeDuplicates`, `reductions`, `AsyncTimerSequence`, `.async`; `@CasePathable` with `.is` and `[case:]`; `OrderedDictionary` and `OrderedSet` where order is read.

## [02]-[LAYOUT]

20. `JSONRPC` sits under `core` and stays host-free: it takes lines in as `some AsyncSequence<Data>` and a writer out as a value, logs nothing, and the consumer binds it to a `Subprocess` execution or file handles.
    `Server.swift:1` `CurrentProcess` import and the execution-bound connection → values the consumer supplies
21. `Package.swift` lists each module as `.target(name:dependencies:path:)` in `modules`, products derive from `modules`, every `.target` takes the shared `settings` and linker settings, a package product appears in a module's dependencies only where a member of it is called, and a merged module takes the dependencies its files call. The `.xcodeproj` `package-product-members` rows and `xcshareddata/swiftpm/Package.resolved` follow through `xcrun xcodeproj pkg link` and `upgrade:xcode`.
22. A consumer the [03] row names changes in the same run: `tools/watch-apps/WatchApps.swift` (the `Line` encoder, `Set` and `Target` names, trust check, launch facts), `apps/macos/relay` (`CodexClient` over the one connection, backoff values, keychain and lock protocol kept as app content), `apps/creative-cloud/atelier/macos/Atelier.swift` (request vocabulary, walk predicate, PNG policy, Adobe rows), the modules importing a rebuilt module.
