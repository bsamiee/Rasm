## Corrections and findings

- `Fin<A>.Succ` and `Fin<A>.Fail` are nested classes. The module functions `Fin.Succ<A>(A)` and `Fin.Fail<A>(Error)` exist and resolve; the file uses the implicit lift instead, so one construction path stays in the doc.
- `Fail(new TooLarge())` does not lift into `Fin<int>`: inference yields `Fail<TooLarge>`, and `Fin<A>` converts only from `Fail<Error>`. Spell it `Fail<Error>(new TooLarge())`.
- `guard(flag, new InvalidAge())` selects `guard<E>(bool, E)` with `E = InvalidAge` and returns `Guard<InvalidAge, Unit>`, which `Fin` LINQ rejects. Spell it `guard<Error>(flag, new InvalidAge())`.
- `ManyErrors.IsType<E>()` is `Errors.Exists(e => e.IsType<E>())`, so `many.IsType<ManyErrors>()` is false for a `ManyErrors` (run evidence: the check `many is ManyErrors && !many.IsType<ManyErrors>()` passes). Accumulation is detected with `Count` or an `is ManyErrors` pattern, never with `IsType<ManyErrors>()`. `Filter<E>` on `ManyErrors` keeps the matching leaves.
- `when`/`unless` signatures in `DECOMP/sigs/Prelude.txt`: `K<F, Unit> when<F>(bool flag, K<F, Unit> alternative) where F : Applicative<F>` and the same for `unless`; the monadic forms take `K<M, bool>`. Only the `bool` forms are used and compiled.
- `IO<A>.Catch(Func<Error, bool>, Func<Error, K<IO, A>>)` is a virtual instance method that returns `IO<A>` without `.As()`; the code and value overloads are `FallibleExtensions` returning `K<IO, A>` and need `.As()`. The doc shows `Catch(code, f).As()` on `IO`.
- `Age` has a generated private constructor; `Samples` calls `Create` with valid values only, and `(int)a` reads the key where a check needs the `int`.
- `Some(null)` holds `null` (`Some(missing).IsSome` is true), confirming the LAB-NOTES correction; `Optional(null)` is `None`.
- Analyzer: `==` between two `string` values fails MA0006; the sample uses `string.Equals(a, b, StringComparison.Ordinal)`.
