# F01 notes: the functional model

Lab `Lab.F01` builds with zero diagnostics and runs with exit 0. `Samples.Run()` checks every sample outcome.

## Members verified

- `Prelude.Range(int from, int count, int step = 1) : Range<int>`; `toSeq(Range(1, 3)) == Seq(1, 2, 3)`.
- `Prelude.toSeq(IEnumerable<A>)` over the LINQ `Order()` result; `toSeq(A[])` over `Enum.GetValues<DayOfWeek>()`.
- `Prelude.Seq(a, b, c) : Seq<A>`.
- `Seq<A>.Map(Func<A, B>) : Seq<B>`; a `Func<int, int>` local passes as the argument.
- `Seq<A>.Filter(Func<A, bool>) : Seq<A>`; a capturing (non-static) lambda inside a local function compiles as the closure sample.
- `Seq<A>.Order()` resolves to `Enumerable.Order` through `IEnumerable<A>`; the source `Seq` is unchanged after it.
- `Seq<A>.Count`; `Seq<A> == Seq<A>` equality on `int` and `DayOfWeek` elements.
- `Prelude.Some(A) : Option<A>`; `Prelude.None` is `Fail<Unit>` and converts implicitly to `Option<int>`; `Option<A>.IsNone`.
- `Prelude.parseInt(string) : Option<int>`.
- `Prelude.Map((K, V)) : Map<K, V>` with `Find(K) : Option<V>`; `Prelude.HashMap((K, V)) : HashMap<K, V>` with `Find`; `Prelude.Set(a, b, c) : Set<A>` with `Contains`.
- `K<F, A>` with `where F : Functor<F>`: `values.Map(f)` returns `K<F, B>`; `Tripled(Some(2))` infers `F` as `Option` and `Tripled(Seq(1, 2, 3))` infers `Seq` with no explicit type arguments; `.As()` recovers `Option<int>` and `Seq<int>`.
- `K<M, A>` with `where M : Monad<M>`: `values.Bind(x => M.Pure(...))` compiles and runs over `Option` and `Seq`.
- `K<F, A>` with `where F : Applicative<F>`: `F.Pure(value)` called as `Lifted<Option>(1).As()` and `Lifted<Seq>(1).As()`.
- `List<int>` collection expression `[7, 6, 1]` and `Sort()` as the impure contrast.
- `DateTimeOffset` inside `string.Create(CultureInfo.InvariantCulture, $"{now} ...")` formats as `01/02/2024 03:04:05 +00:00`.
- `internal sealed record DoctorWho(...)` with a multi-line `with { ..., }` initializer under a trailing comma.

## Corrections to the plan and the API document

- CORRECTION (plan): the implicit `DateTime` to `DateTimeOffset` argument conversion fails as MA0132 ("Do not convert implicitly to DateTimeOffset"), not MA0133. Probe: `TimestampedGreeting(new DateTime(...), "Ada")` under the lab analyzers.
- Confirmed (plan): `OrderBy(static x => x)` fails MA0159 ("Use 'Order' instead of 'OrderBy'") and RCS1077. `toSeq(values.Order())` is the compiled form.
- The `logger.LogInfo` fragment from the book never compiled (no `logger`); `Console.WriteLine` stands in as the effect, the smallest change that keeps the `Action<string>` teaching point.
- `$"{x} + {y} = {x + y}"` with `int` holes fails MA0076 as a bare interpolation; `string.Create(CultureInfo.InvariantCulture, ...)` is the compiled form. `$"message received: {message}"` with one `string` hole stays bare (MA0185 rejects `string.Create` there).
- `StartsWith(string)` without a `StringComparison` fails the analyzers; the closure sample passes `StringComparison.Ordinal`.
- MA0003 requires a named `null` argument (`Greeting(name: null)`), so the lab checks name the parameter.
