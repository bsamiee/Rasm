# [SCARS]

Regression-proven law with no other owner: each scar is standing law, and its trigger names the falsifiable failure mode the law forecloses. Gaining a real owner — a gate, a doctrine page, a skill — moves the scar there and leaves no copy.

## [01]-[LEDGER]

[RETIRED_SURFACE_DRAIN]:
- Law: Retired surfaces drain only on corpus-wide proof of zero occurrences.
- Trigger: Stale spellings beyond the finding set resurface silently.
- Boundary: Drains span every retired-surface kind — a tool-manifest row, a renamed member, a deleted flat property, a strata-banned parameter type.
- Boundary: Anchor and finding lists are navigation, never the drain boundary.

[BLOCKER_HYPOTHESIS]:
- Law: Recorded blockers re-prove on their verification rail before gating any work; the marker is a hypothesis, never a constraint.
- Trigger: Cards block on conditions already met — members their own catalogs already carry, an `[Obsolete]` decorating a neighbour read as decorating the member, a namespace mistaken for an absent package.
- Boundary: Re-probes run on the owning rail — assay decompile, venv reflection, `node_modules` inspection; a blocker surviving the probe keeps its Arms row verbatim.
- Boundary: Lane findings, alignment rows, and charter text inherit the same law — a claim carried from a report without a disk re-probe is a hypothesis wearing charter clothes.

[ASSERTED_VALUE]:
- Law: Readable values fill from their surface's read; a hand-asserted copy of a readable value is a defect on sight.
- Trigger: Asserted flags, tenancy claims, and capability columns diverge silently the first time the surface they mirror moves, and nothing raises.
- Boundary: Spans fence literals and prose claims alike — a comment asserting a behavior the member contradicts falls with the literal.

[FORGED_ZERO]:
- Law: Tallies, levels, and receipt fields publish only measured values; a construction that can only produce zero for an absent measurement spells absence instead.
- Trigger: Zero-fallback reads, retired-owner slots republishing a last value, and zero-filled sealed receipts each read as live measurements no producer took.
- Boundary: Design law at `libs/.planning/RULINGS.md` `[02]-[SHAPE]` owns the diagnostic-plane UNMEASURED shape; this scar binds every other counter, ledger, and receipt construction.

[STRATA_TWIN]:
- Law: Concepts two strata peers both spell home at the lowest stratum every consumer reaches before either peer declares them; a same-named type twin between peers is a seating failure, never a naming coincidence.
- Trigger: Two divergent twins reach one compile leg, and dispatch resolves against whichever twin a page happened to cite.
- Boundary: Shared consumers are the twin test, never shared spelling alone — a genuinely distinct concept keeps a distinct name.

[UNREAD_KEY_ROW]:
- Law: Policy, config, and provisioning rows prove their named consumer reads the keys they spell before landing; a row keyed to a coordinate its consumer never reads governs nothing.
- Trigger: Governance rows bound to environment keys no deploy plane publishes, a secret whose chart reads a different key name, a datasource row whose driver ignores the field it spells.
- Boundary: Proof is the consumer's own read path — chart template, options binder, driver config — never the key's existence in documentation.
