# [TS_CORE_API_RFC6902]

`rfc6902` supplies RFC 6902/6901 mechanics beneath `Format.Patch`. `Format.Patch` owns admission, root semantics, token safety, and concurrency policy; the package receives only decoded non-root operations.

## [01]-[PUBLIC_TYPES]

[PUBLIC_TYPE_SCOPE]: patch vocabulary and package faults

| [INDEX] | [SYMBOL]                                                | [TYPE_FAMILY]   | [CAPABILITY]                                     |
| :-----: | :------------------------------------------------------ | :-------------- | :----------------------------------------------- |
|  [01]   | `Operation` / `Patch`                                   | operation union | six RFC operations and an ordered document       |
|  [02]   | `AddOperation` / `RemoveOperation` / `ReplaceOperation` | mutation rows   | `path` with optional replacement value           |
|  [03]   | `MoveOperation` / `CopyOperation`                       | relocation rows | `from` and `path` pointers                       |
|  [04]   | `TestOperation`                                         | assertion row   | structural equality assertion; not OCC authority |
|  [05]   | `MissingError` / `TestError` / `InvalidOperationError`  | fault values    | per-operation failure slots                      |
|  [06]   | `Options`                                               | apply policy    | optional implicit array creation                 |

[PUBLIC_TYPE_SCOPE]: pointer and diff substrate

| [INDEX] | [SYMBOL]                        | [TYPE_FAMILY] | [CAPABILITY]                        |
| :-----: | :------------------------------ | :------------ | :---------------------------------- |
|  [01]   | `Pointer` / `PointerEvaluation` | pointer value | RFC 6901 tokenization and traversal |
|  [02]   | `escapeToken` / `unescapeToken` | token codec   | `~0` and `~1` crossing              |
|  [03]   | `Diff` / `VoidableDiff`         | diff hook     | domain hook with package fallback   |
|  [04]   | `isDestructive`                 | classifier    | mutation classification             |

- Empty pointers evaluate the document root, but the package mutators do not provide the branch's safe root-value contract.
- Pointer decoding does not establish prototype-token admission; `Format.Patch` validates every `path` and `from` token first.

## [02]-[ENTRYPOINTS]

[ENTRYPOINT_SCOPE]: diff and test helpers

[ENTRYPOINT_SCOPE]: apply and traversal

| [INDEX] | [SURFACE]                                               | [ENTRY_FAMILY]    | [ADMISSION]                         |
| :-----: | :------------------------------------------------------ | :---------------- | :---------------------------------- |
|  [01]   | `applyPatch(object, patch, options?)`                   | apply document    | safe non-root operations only       |
|  [02]   | `apply(object, operation, options?)`                    | apply row         | adapter-selected non-root operation |
|  [03]   | `add` / `remove` / `replace` / `move` / `copy` / `test` | operation engines | never receive an unvetted pointer   |

- `applyPatch` returns one `Error | null` slot per operation and mutates its input.
- `createPatch` and `createTests` are package algorithms, not authorization or concurrency boundaries.

## [03]-[IMPLEMENTATION_LAW]

[TOPOLOGY]:
- `Format.Patch` decodes the six operation rows before package code receives them; raw package `any` never crosses the boundary.
- `Format.Patch` decodes `path` and `from`, rejects prototype-bearing tokens, and never delegates a root-involved operation.
- `Format.Patch` owns the typed root successor because package pointer evaluation yields a null parent at the empty path.
- Package `test` is a value assertion; journal/version admission owns atomic OCC, and `createTests` cannot mint that authority.
- The adapter clones the admitted document, delegates safe non-root rows, and folds package fault slots into its typed `Effect` rail.
- Package-generated diff and test rows re-enter the same schema, pointer, root, and authority fences before egress.

[STACKING]:
- `effect` (`.api/effect.md`): `Schema` owns operation ingress, `Match` owns root/non-root dispatch, and `Effect` carries typed faults.
- `interchange/format`: `Format.Patch` owns the adapter; `rfc6902` stays an internal non-root engine.
- `state/causal` and `data/journal/append`: the atomic version precondition owns OCC independently of JSON Patch assertions.
- `value/contentKey`: encoded admitted operations reuse `Digest`; the package mints no identity.

[LOCAL_ADMISSION]:
- Decode first, reject unsafe pointer tokens, route root involvement through `Format.Patch`, then delegate cloned non-root state.
- Re-admit every `createPatch` result; `createTests` may supply assertions but never the journal's OCC credential.
- Fold package result slots through the adapter fault rail; no raw package error or mutated ingress escapes.
