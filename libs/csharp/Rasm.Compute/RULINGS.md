## [02]-[SHAPE]

- `Model/inference#STAGE_EXECUTION` mirrors the photo-to-PBR request and result records but transcribes no stage, product, or model-card roster: those vocabularies grow by row at `Rasm.Materials`, and a mirrored roster turns every admitted model into a Compute edit. Only `LicenseClass` re-declares here, the one family this end dispatches on, because a grant enforced solely where the request is built trusts the caller's word.
- ONNX output tensor NAMES are the product roles. Stage requests carry no output roster, so the executor emits one product per `InferenceSession.OutputNames` entry under that name and the specifying end resolves it against its own vocabulary; binding model outputs to declared roles by ordinal couples two independently versioned rosters by position and silently mis-labels a re-exported model's planes.
- ONE tiled grid carries EVERY product a forward pass emits. `Model/inference#TILED_INFERENCE` `TilePlan` holds an ordered `TileProduct` roster and `InferTiled` scatters each result of one run into its own plane, so an estimator emitting base colour, normal, and roughness together costs one grid; a fold that opens a flow per output name re-infers the whole image once per plane the model already produced, and the multiplier is invisible because each pass looks correct alone.
- `Model/providers#EP_AXIS` owns every cross-boundary spelling of its own rows as a `WireKey` column on `ExecutionProvider` and `ModelPrecision`, so records crossing a boundary hold no translation table and a row landing later crosses by declaring one string. Unresolvable PROVIDERS degrade to the floor because the consuming record reports what ran; unresolvable PRECISIONS refuse because no wire column reports a substituted posture, and a default there runs one precision while the receipt names another.
- `FieldMask` has one mint and one apply — `WireServices.Mask` alone constructs and validates masks at the wire edge (`FieldRef` admission under the `FieldMask.IsValid` gate), while `FrameEdge.Patch` alone merges validated masks onto live messages under the transport frame law; a dedup sweep reading the twin `Union`/`Normalize` calls as duplication folds the apply leg into the mint and couples frame application to wire-edge admission — one mask-shape change then breaks both seams in one edit.

## [03]-[COLLAPSE]

- Tiling plans are CONSTRUCTED once and compared never. `Model/inference#STAGE_EXECUTION` `StageRequest.Plan` folds the wire's extent, bucket, overlap, pad, and scale columns into the `TilePlan` whose validator is the sole spelling of the fixed-bucket law, and that value seats the bound flow and drives the fold.
- Request-side predicates restating a plan law, a session-supplied plan beside the built one, and a compare catching the two drifting are ONE defect in three parts: the compare reports a disagreement it never explains, and each rule edit lands thrice or silently once.
- `TilePlan` owns the taper-weight accumulation and the layout rows own only the product kernels. Weight is per-texel geometry every product shares, so a scatter kernel carrying it accumulates one taper mass per plane per window and forces every new layout row to re-derive that geometry identically.
