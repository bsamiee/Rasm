Reach · the model boundary

Who reads each element

Everything a mod draws or plays reaches the person alone. The model reads only the answers and calls in the second table, so an agent learns about a drawing only when the plugin that drew it also uses one of those channels. The tables list the channels a mod writes; they are not a closed set of everything that shapes a request.
