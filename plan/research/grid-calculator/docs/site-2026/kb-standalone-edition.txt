About Grid Calculator Standalone Edition
What Grid Calculator SE is, how it differs from the plug-in, and what to expect at launch.
What is Grid Calculator SE?
Grid Calculator Standalone Edition is a desktop app currently in development. Unlike the InDesign plug-in (Grid Calculator PE), SE runs as its own application — no InDesign installation required.
What will it do?
Design your grid layout in Grid Calculator SE, then export it directly into:
Adobe InDesign
 — creates a fully configured document with margins, columns, and baseline grid pre-applied
Affinity Publisher
 — exports a template with the equivalent grid settings mapped to Affinity’s layout system
