# [ILLUSTRATOR]

Illustrator is driven through three channels: the official Adobe MCP server for everything in its surface, `osascript` `do javascript` over a built ES3 `.jsx` for everything the official server lacks, and the GUI through the accessibility reader and computer-use for the surfaces that carry no scripting property. This file owns the host facts, the channel, the script project, the tool contracts, the data files, the add-ons, and the application configuration pass. Use `plan/design/server.md` for the error vocabulary, the job model, and the host table. Use `plan/design/typography.md` for the grid mathematics and the page-size catalogue.

Evidence classes: `[DISK]` read from this machine, `[DOC]` read from a dated document, `[LIVE]` measured on this machine through `osascript`, `do javascript`, or the official MCP, `[IMG]` read from a computer-use screenshot, `[DECIDED]` a choice this file makes. Every claim with no class is unverified and carries a row in [15].

Preset masks in the order left, top, right, bottom, centerX, centerY, leftDiagonal, rightDiagonal: `all` sets all eight, `bounds` the first four, `onlyCenters` the two centres, `onlyDiagonals` the two diagonals, `boundsAndCenters` the first six.

Guide colour is read from Illustrator's own preferences, `255 * app.preferences.getRealPreference("Guide/Color/red" | "…green" | "…blue")`, which is an `RGBColor` directly in an RGB document. A CMYK document converts RGB to HSV to CMYK after two corrections: `if (s < 20 && v > 80) v = 50` and `if (s > 10) s = 100`.

Algorithm: margins convert to pixels and divide by `doc.scaleFactor`; the chosen bounds expand as `b[0] -= mL; b[1] += mT; b[2] += mR; b[3] -= mB`; per selected object a group named `<objectName>_guides` is created in the target layer; horizontals emit at `top`, `bottom`, `centerY`, verticals at `left`, `right`, `centerX`, diagonals as `[left,top]→[right,bottom]` and `[right,top]→[left,bottom]`. Each segment lengthens by `d` at both ends along its own unit vector:

```text
len = sqrt(dx*dx + dy*dy); ux = dx/len; uy = dy/len
p1' = [p1x - ux*d, p1y - uy*d];  p2' = [p2x + ux*d, p2y + uy*d]
```

With `percentage`, `d = (dimension * pct) / 100`, where `dimension` is the object's width for a horizontal, its height for a vertical, the diagonal's own length for a diagonal, or the artboard's corresponding dimension when extending to the artboard. With `absolute`, `d` is the converted length. For the artboard and canvas targets a containment test skips a segment already inside the rectangle, and a diagonal is clipped by line and rectangle intersection with `k = (p2y - p1y)/(p2x - p1x)` and `b = p1y - k*p1x`, testing the four candidates at the rectangle's four edges and drawing only when exactly two survive. Empty groups are removed. Items carry `filled = false`, `stroked = true`, `strokeWidth = 0.25`, the guide colour, and `.guides = true` when `drawAs` is `guides`; the layer is raised with `zOrder(ZOrderMethod.BRINGTOFRONT)`.

### [06.3]-[BENTO_GRID]

Two modes, one input union. Grid box comes from the selection's unioned `geometricBounds` (a group, a clipped group, and a compound path are duplicated into a temporary layer, flattened with `executeMenuCommand("noCompoundPath")` and `"group"`, measured, and the layer removed) or from the active artboard's `artboardRect`. Cells are `container.pathItems.roundedRectangle(top, left, width, height, radius, radius)`, moved back to front into one group so the stacking order holds, and the group is named `BENTO`, `BENTO_TOTAL`, `BENTO_HERO`, or `BENTO_HERO_CENTER` by mode. No layer is created for the artwork, and each rectangle carries the document's new-path appearance.

`grid` mode inputs: `columns` and `rows` as a count or a range, `columnGutter`, `rowGutter`, `splitColumns` and `splitRows` with a first-cell percentage range, `cornerRadius`. Column count is `randomInt(colMin, colMax)`; each column draws its own `randomInt(rowMin, rowMax)`; `colW = (grid.w - (colCount - 1) * colGutter) / colCount` and `rowH = (grid.h - (rowCount - 1) * rowGutter) / rowCount`. A cell becomes a split when the toggle is on, `Math.random() > 0.5`, and the previous cell was not itself the same split; the ratio is `min/100 + Math.random() * (max - min)/100`, and the geometry is `left = (colW - colGutter) * ratio` with `right = (colW - colGutter) - left` for a row split, `top = (rowH - rowGutter) * ratio` with `bottom = (rowH - rowGutter) - top` for a column split. The walk advances `x += colW + colGutter` and `y -= rowH + rowGutter`, because the y axis points up.

`total` mode inputs: `maxCount`, `gutter`, `minSize`, `hero`, `centerHero`, `cornerRadius`. A largest-leaf-first guillotine packer runs to at most 1000 iterations:

```text
rect = the leaf with the largest area
canH = rect.w >= 2*minSize + gutter;  canV = rect.h >= 2*minSize + gutter
splitHoriz = rect.w > rect.h, forced when one axis alone fits
if (canH && canV && Math.random() < 0.3) splitHoriz = !splitHoriz
avail = (splitHoriz ? rect.w : rect.h) - gutter
size  = clamp(minSize + Math.random() * (avail - 2*minSize), minSize, avail - minSize)
```

Clamping is the correction: the reference's guards test `2*minSize + gutter` against the pre-gutter dimension while `avail` is already gutter-reduced, so an undersized cell survives them. The hero cell scales by `0.45 + Math.random() * 0.2`, `heroW = max(grid.w * scale, minSize)` and `heroH = max(grid.h * scale, minSize)`, centred on request and otherwise placed randomly and snapped to an edge whenever the remaining gap falls below `minSize + gutter`. Up to four surrounding zones emit, each only when its strip is at least `minSize` wide, each carrying its own reach flags, and the remaining `maxCount - 1` cells distribute across the zones with every zone taking at least one before the leftovers land at random.

### [06.4]-[ISOMETRIC_GRID]

Inputs `spacing` (72 pt in the reference), `angle` (60°), and `artboards`. The entry saves `doc.rulerOrigin`, sets it to `[0, doc.height]` then to the artboard's `[left, top]`, switches to `ARTBOARDCOORDINATESYSTEM`, and restores both at the end. With `x2 = left + width/2`, step `i = spacing`, and ring counter `c = 1`: three seed lines `l`, `k`, `m` each run `x2, top - height` to `x2, bottom + height`, with `l` and `k` taking `height += height` and `top += height/2`. Per ring, `m` duplicates at `±(i*c)` and at `±(i*c)/2` while `x2 + i*c <= right`; `k` duplicates at `±(i*c)` rotated by `-angle` about `Transformation.CENTER`, and the loop ends when that copy's `top + height/2` is at or above the artboard top, which removes the copy; `l` duplicates at `±(i*c)` rotated by `+angle`. After the loop `l` rotates `+angle`, `k` rotates `-angle`, and all three join the collection. Clipping adds a group, a `pathItems.rectangle(abTop, abLeft, abWidth, abHeight)` moved to the group's beginning, every line moved to its end, and `group.clipped = true`. Output is one clipped group per artboard inside a sublayer named `<artboard name> iso grid` under a layer named `ISOGrid`.

### [06.5]-[ARTBOARD_DUPLICATION]

Inputs `copies`, `columns`, `spacing`, `nameTemplate` (`%a` the source name, `%n` the copy index), `insertLast`, `copyArtwork`. The canvas half-extent is 16383 points. A document-relative box is measured by probing:

```text
shift  = 1 + (((probe.position[0]*2 - 16384) - (probe.position[1]*2 + 16384)) / 2)
left   = floor(abRect.position[0] - probeRect.position[0])
top    = floor(probeRect.position[1] - abRect.position[1])
right  = left + width;  bottom = top + height
```

One 300 × 300 rectangle sits at `[probe.pos[0] - shift, probe.pos[1] + shift]` with an artboard-sized rectangle beside it, and every probe object is removed afterwards. The width check is `stepX = (right - left) + spacing` with `lastRight = right + stepX*(columns - 1)`, rejecting when `lastRight > 16383` and reporting how many columns fit. The height check counts `rowsUsed` as the copies where `(i+1) % columns == 0`, takes `stepY = (bottom - top) + spacing`, rejects when `bottom + stepY*rowsUsed > 16383`, and reports `(columns - 1) + columns*rowsUsed` as the number that fits.

Per copy, with `n` the one-based index, `wrap = (n % columns) == 0`, `row = n / columns`, `h = ab[3] - ab[1]`, `w = ab[2] - ab[0]`, and `prev` the previous new rectangle:

| [INDEX] | [CASE]              | [RECT]                                                                     |
| :-----: | :------------------ | :------------------------------------------------------------------------- |
|  [01]   | `wrap`              | `[ab[0], ab[1] - spacing*row + h*row, ab[2], ab[3] - spacing*row + h*row]` |
|  [02]   | First copy, no wrap | `[ab[2] + spacing, ab[1], ab[2] + spacing + w, ab[3]]`                     |
|  [03]   | Later copy, no wrap | `[prev[2] + spacing, prev[1], prev[2] + spacing + w, prev[3]]`             |

`%n` is the copy index zero-padded to `String(copies).length` digits. Creation is `artboards.add(rect)` when `insertLast`, else `artboards.insert(rect, sourceIndex + n)`. Artwork copying unlocks and unhides recursively while holding each item's prior state in memory, runs `doc.selectObjectsOnActiveArtboard()` and `duplicate()` per selected item, offsets each duplicate by `[newRect[2] - ab[2], newRect[1] - ab[1]]` through `doc.convertCoordinate(pos, DOCUMENTCOORDINATESYSTEM, ARTBOARDCOORDINATESYSTEM)` when the application is in document coordinates, and restores the state at the end.

### [06.6]-[TEXT_HIGHLIGHT]

Measurement runs through outlines rather than font metrics, which is the technique worth carrying. Whole-frame mode, per `line` of `textFrame.lines`: clone a one-line frame from `characters[0].duplicate(insertionPoint)` and set `contents` to the line, or to the measurement glyph when the line is blank; advance `top -= leading` per iteration and align horizontally by `Justification` against the frame's `left` and `width`; duplicate, `createOutline()`, and read `geometricBounds` and `width` for the box width; duplicate again with `contents` overridden to the single measurement glyph, outline it, and read that outline's `height` and `geometricBounds[1]`; remove both temporaries. Range mode finds the intersecting frames, duplicates, outlines, groups the resulting paths, counts whitespace runs matching `\s|\x03|\f|\r\n|\r|\n` before and inside the range so unmarked glyph paths are skipped, and slices `pageItems` for the range into a temporary group for `left` and `width`.

Geometry, with `dest` the measured box:

```text
boxW = isAbsW ? rW : dest.width;  boxH = isAbsH ? rH : dest.height
lineEndX = boxW * (isAbsW ? 1 : rW) + left
```

Each of the nine anchors applies its half or full delta; the centre case is `left -= 0.5 * (boxW - dest.width)` absolute or `left += 0.5 * boxW * (1 - rW)` relative, and `top += 0.5 * (boxH - dest.height)` absolute or `top -= 0.5 * boxH * (1 - rH)` relative. Then `top -= (0.5 * boxH * (isAbsH ? 1 : rH) - offset)` and `right = left + lineEndX`.

Reference output is a stroked two-point open path whose stroke weight carries the height. The replacement emits a rectangle: height is that weight, the rectangle re-centres on the baseline, and `strokeDashes` becomes a dashed rectangle edge when dashes are on. The zigzag applies Illustrator's own live effect through `applyEffect` with `<LiveEffect name="Adobe Zigzag"><Dict data="R amount #1 R relAmount #2 R absoluteness #3 R ridges #4 R roundness #5 "/></LiveEffect>`, substituting size, relative amount, absoluteness, ridge count, and smoothness. Colour converts through `app.convertSampleColor(ImageColorSpace.RGB | CMYK, …, ColorConvertPurpose.defaultpurpose)`, and a spot colour is duplicated rather than flattened. Each highlight moves with `move(dest, ElementPlacement.PLACEAFTER)` onto the source object's own layer, and `groupPerFrame` puts every highlight of one frame in one group.

### [06.7]-[GRADIENT_BLEND]

Gradient collection walks `selection`: a group recurses into `pageItems`, and a path or compound path contributes when `fillColor` or `strokeColor` has `typename === "GradientColor"` and exposes `gradientStops`. Results deduplicate by object identity, so a gradient several objects share is processed once. Optionally every intermediate stop is removed, keeping the two endpoints. Every remaining stop is snapshotted as `{pos, color, opacity}`, `(precision - 1) * (stopCount - 1)` stops are added, and `gradientStops[last].rampPoint` is pinned to 100 for the rewrite. For an index that is not a multiple of `precision`:

```text
rampPoint = previous.rampPoint + (next.pos - current.pos) / precision
opacity   = previous.opacity   + (next.opa - current.opa) / precision
color     = mix(from, to, (i % precision) / precision, space, hueArc)
```

Every index that is a multiple of `precision` restores the original stop verbatim and advances the `from` and `to` pair. The last stop's position is restored and `redraw()` runs. Mixing is componentwise linear interpolation, `out[i] = a[i] + (b[i] - a[i]) * t`, after endpoint resolution: a spot at tint 100 resolves to `spot.color` and a lower tint mixes toward white by `1 - tint/100`; a gray converts through `convertSampleColor(GrayScale, RGB, …)`; two pure-K CMYK endpoints skip the colour space entirely and interpolate the black channel alone; and every RGB result converts back with `convertSampleColor(RGB, CMYK, …)` in a CMYK document. Gradient meshes are out of scope, and the native stop midpoint is never touched.
