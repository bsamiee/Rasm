HIG "The menu bar" (https://developer.apple.com/design/human-interface-guidelines/the-menu-bar) states the bar is 24pt and asks for a symbol or a black/clear template icon; the current page no longer states 16x16 or 18pt, so the SF Symbol measurements above set the target.

Set in `apps/relay/Assets.xcassets/RelaySymbol.imageset/RelaySymbol.svg`: intrinsic 16x16 with `viewBox 0 0 16 16`, every coordinate scaled 0.8 and recentered on the 16pt canvas, stroke 1.15, dot radius 1.1. Measured result: bbox 14.00x12.50pt, stroke 1.12pt, the same as clock and magnifyingglass; a composite render beside wifi, clock, magnifyingglass, and sun.max at the menu bar configuration (scratchpad `compare.png`) shows the mark at parity. `Contents.json` already carries `template-rendering-intent: template` and `preserves-vector-representation`; `RelayApp.swift` draws `Image("RelaySymbol")` with no `resizable` or `frame`, so the 16pt intrinsic size is the rendered size.

App icon: HIG "App icons" (https://developer.apple.com/design/human-interface-guidelines/app-icons) now specifies 1024x1024 square layers the system masks; the flattened macOS grid is an 824x824 plate at a 100 inset with a 185.4 corner radius (Apple Developer Forums thread 761179, citing thread 670578). `RelayArtwork.svg` had an 896 plate at 64 inset with rx 200; set the rect to 824/100/185.4 and the glyph group to `translate(248 248) scale(22)` so the mark keeps its proportion to the plate. The shipped 1024 PNG was pixel-identical to an Inkscape render of the old SVG (AE 0), so the ten PNGs were regenerated with Inkscape 1.4.4; trims confirm 824+100 at 1024 and 14+1 at 16.
