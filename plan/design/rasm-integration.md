# [RASM_INTEGRATION]

Integration of `apps/creative-cloud` and `libs/typescript/{host-bridge,typographic-grid}` into the Rasm monorepo, in the repo's own form. Every row states a repository fact with the file and line that holds it on 2026-09-14, a documented fact with its source in [08], or a target the command in its [PROOF] column proves; a row that needs a running Adobe host names its probe. The executing agents of Stage 1 copy the forms in [03] and [04] ([06] steps [01]–[04] and [10]–[15] are the checks-and-rules task, steps [05]–[09] the scaffold task); [09] holds the commands the verifier re-runs over the tree and their expected readbacks. The project graph is `architecture.md` [02], the transport and install rows `architecture.md` [05], the build pipelines `architecture.md` [09]; this document owns how those projects join the tree.
