I want to touch upon the area of 'Value Mode', an option found in the margins section which allows you to set your margins to desired values. You can see the 'Value' options checked in the image below.

Version 4.2 is not a big update in terms of new features but more so in terms of update of the software code. Without writing a long article, I strongly suggest saving your actual document when setting up your layout with 'Value'. Due to the complexity of the setup the plug-in is unable to save all rows correctly in masters GC-2 to GC-5.

It is always recommended to save the actual document instead of just the preset. If possible we will release an update to address this issue in the future. However, by saving the document itself everything will work fine.
