- CA1508 (lab side): `(int)TypesToRenderAsString.All == 7` is a constant condition. The lab check parses the name at runtime with `Enum.Parse<TypesToRenderAsString>("All")`.
- EPC20 and MA0150 (lab side): `Quantity.Create(3).ToString()` flags the default `object.ToString`. The lab checks `typeof(Quantity).GetMethod(nameof(ToString), Type.EmptyTypes)?.DeclaringType != typeof(Quantity)` instead.
- `MessageTemplateTextFormatter("{Message:j}")` renders compact JSON (`{"Lower":1,...}`) while the console sink renders with spaces (`{"Lower": 1, ...}`). The lab checks use the compact form, the doc fences quote the console sink.
