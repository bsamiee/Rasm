# [ILLUSTRATOR_ACROBAT_CC]

Integration specification for the three hosts a Rasm application drives from agent-only MCP servers: one stdio server named `creative-cloud` with host-prefixed tools (`illustrator_<verb>`, `acrobat_<verb>`), beside the official `illustrator` MCP row. Written 2026-09-11 from the installed bundles, dictionaries, and preference files on this machine, read-only probes through `osascript`, and the official documentation fetched the same day. Illustrator is driven through ExtendScript alone, over the AppleScript `do javascript` channel. Evidence classes: `[DISK]` read from this machine, `[DOC]` read from a dated document, `[LIVE]` measured on this machine through `osascript`, `do javascript`, or `do script`, `[INFER]` derived from two verified facts, `[OPEN]` unverified. The driver, its error vocabulary, and the project layout are owned by `applescript-integration.md` and `architecture.md`; this file cites them and repeats nothing they own.
