# [GUI_ILLUSTRATOR]

GUI specification for the installed Adobe Illustrator (Beta) (`illustrator.version` and `illustrator.buildNumber` of `.artifacts/creative-cloud/resolved-paths.json`; the live app answers `app.version` `30.9.0`, `app.buildNumber` `72R`), the reference layout every other application mirrors. The current layout, workspace, and toolbar of this machine are the baseline: every target below reads "current kept, plus the named change", and the proof of the baseline is the live dump `<Inputs>/ax/illustrator.json` (`status`, `menus`, `tree`, `windowlist`; regenerated through `AxDump` at G10 with the app idle, `ax-README.md` [01]). Both prefs files, the workspace, and the toolbar file are rewritten when the app quits, so every file edit below waits for a quit and is verified after the next launch. Evidence classes: `[DISK]` read from this machine, `[DOC]` a dated Adobe page, `[PLAN]` a value a probe measured, `[LIVE]` a read-only answer of the running app (`osascript … do javascript`, the official `illustrator` MCP, or the AX dump), `[IMG]` a computer-use screenshot with the document `default-template.ai` open (coordinates in its 1372 px wide frame; the same display is 1800 pt wide in the AX frame, so 1 px = 1.31 pt), `[DECIDED]` a choice this document makes, `[OPEN]` a claim with a numbered probe row in [09].

Paths used below: `<Prefs>` = `<illustrator.prefsFolder>/en_US/`, `<Support>` = `<illustrator.supportFolder>/en_US/`, `<App>` = `<illustrator.installFolder>/`, every one a key of `.artifacts/creative-cloud/resolved-paths.json` ([08] row 01), the folder names following the installed edition, and `<illustrator.bundlePath>`, `<illustrator.bundleId>`, `<illustrator.processName>` read from the same file wherever a command names the bundle or the process; `<Drive>` = `~/Library/CloudStorage/GoogleDrive-b.samiee@mzn-group.com/My Drive/03.Digital Asset Database/05.Software Related Assets/99.Default Profiles/00.Adobe Illustrator/`; `<Palette>` = `~/Library/CloudStorage/GoogleDrive-b.samiee@mzn-group.com/My Drive/03.Digital Asset Database/02.Color Swatches/My Color Palette.ai` (the unified swatch set, read as `<Inputs>/illustrator/d-my-color-palette.json`); `<Sources>` = `plan/research/sources` (read-only); `<Inputs>` = `plan/inputs/`; `<S>` = the probe dump folder `<Sources>/illustrator/`. ### [02.4]-[HOUSE_SHORTCUTS]

One scheme for every app: a tool keeps the letter its shape family owns, the line family sits on `Q` and `Shift+Q`, and a tool held by more than one app carries one letter everywhere, the apps' shared factory letter where the factory sets agree and Illustrator's letter where they differ. Tool shortcuts take a single key or `Shift` plus a key in Illustrator, InDesign, and Photoshop (the factory `.kys` `/Tools` rows carry `/Modifiers 0` or `32` alone). Illustrator's factory tool keys are the `/Tools { /<tool string> { /Context 0 /Modifiers <0|32> /Represent <ascii> /Key <ascii> } }` rows of `<App>/Presets.localized/en_US/Keyboard Shortcuts/Illustrator Defaults.kys` (59,810 B, CR line endings, `/Menus` block then `/Tools`, 744 rows; `32` = Shift; `/Key` and `/Represent` are the ASCII code of the letter, `Q` = `81`) `[DISK]`.
