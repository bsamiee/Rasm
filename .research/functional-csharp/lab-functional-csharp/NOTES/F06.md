Lab: `.scratch/lab-f06` (copied to `.scratch/lab-functional-csharp/F06`), namespace `Lab.F06`. Build: zero diagnostics. Run: exit 0, every check in `Samples.Run()` passes. A wrong expectation in the first run failed with exit 1 and named the check, so the checks execute.

## Members verified (compiled and executed)

- `Prelude.compose<T1, T2, T3>(Func<T1, T2>, Func<T2, T3>) : Func<T1, T3>`. The decompile body is `(T1 v) => b(a(v))`, so `compose(f, g)` applies `f` first and then `g`. The run confirms it: `compose(x => x + 1, x => x * 10)(1)` is `20`. Type arguments infer from typed `Func` fields and from typed lambdas.
- `Prelude.flip<A, B, R>(Func<A, B, R>) : Func<B, A, R>`. `flip(Subtract)(10, 3)` is `-7`. The curried overloads `flip(Func<A, Func<B, R>>)` and the three-argument forms exist and are not compiled.
- `Prelude.fun(Action) : Func<Unit>` inside `IO.lift(fun(connection.Dispose))` as the `Fin` step of `Bracket`.
- `Prelude.use<A>(Func<A>) : IO<A> where A : IDisposable` as the first `from` clause of an `IO` LINQ query; the resource is disposed when the query ends.
- `IO<A>.Bracket(Use: Func<A, IO<B>>, Fin: Func<A, IO<C>>)` with `IO.lift(static () => new Connection())` as the acquisition; the release count rises by one per run.
- `IO.lift(Func<A>)`, `IO.lift(Action)` (returns `IO<Unit>`), `IO.pure`, `RunSafe() : Fin<A>`; `IO.lift(static () => int.Parse("x", ...)).RunSafe()` is `Fail`.
- `Prelude.unless<F>(bool, K<F, Unit>)` and `Prelude.when<F>(bool, K<F, Unit>)` over `IO`, closed with `.As()` to `IO<Unit>`. `unless(stock > 0, ...)` runs the effect for `0` and skips it for `3`; `when(stock > 100, ...)` runs it for `150` and skips it for `50`. The monadic `unless<M>(K<M, bool>, K<M, Unit>)` overloads exist and are not compiled.
- `Try.lift(Func<A>)` then `Run() : Fin<A>`; a thrown `FormatException` arrives as `Fail`.
- `Option<A>`: `IfNone(Func<A>)` runs the function only on `None` (decompile: `if (!isSome) return None(); return Value;` and the miss counter stays at zero after a hit); `IfNone(A)`; `Do(Action<A>)` returns the same `Option` and runs the action on `Some`; `Match(Some:, None:)` with `Func<A, B>` and `Func<B>`.
- `Prelude.parseInt(string) : Option<int>` then `IfNone(fallback)`.
- `HashMap<K, V>`: `HashMap((key, value))` construction, `Find(K) : Option<V>` with `Guid` and `int` keys.
- `Seq<A>`: collection expression into `Seq<Func<A, B>>` with `static` lambdas and into `Seq<(Func<A, bool> When, Func<A, B> Then)>` with tuple literals of `static` lambdas; `Filter`, `Map` (lazy: `SeqLazy` in the decompile), `Do(Action<A>)` (strict: `Iter` then `return this`), `Fold(seed, f)`, `Count`, `ForAll`, `Exists`, `Zip(Seq<B>)` with `Tail` for adjacent pairs, `Add`.
- `ForAll` and `Exists` short-circuit: two rules that count their evaluations run twice for a valid value and once for an invalid one under `ForAll`, and once under `Exists` when the first violation matches. An empty `Seq` gives `true` under `ForAll` and `false` under `Exists`.
- `FoldableExtensions.Find(Func<A, bool>) : Option<A>` on a `Seq` of tuples; the first matching row wins, and `None` selects the fallback.
- `Prelude.Range(int from, int count)` with `toSeq`: `Range(1, 20)` is `1..20`.
- `Trampoline.Pure`, `Trampoline.More(Func<Trampoline<A>>)`, `Run()` at depth 100000; `Monad.recur<IO, int, int>(seed, f)` with `Next.Done`/`Next.Loop` then `.As().RunSafe()` at depth 100000.
- `Atom<A>` with `Swap` and `Value`, `Prelude.ignore` to turn a `Swap` result into `Unit` inside an `Action` lambda (lab scaffolding only).
