Baseline Grid

setup baseline grid

Columns & rows

If you know the number of columns and rows you wish to apply to your layout then Smart mode (that syncs with Modular mode) is the perfect choice. Set your document grid in Modular mode and then in Smart mode simply enter desired number of columns and rows along with gutter and adjust until you find your perfect setting.

Layout Wizard

Which mode fits your project?

Answer a few questions for the Layout Wizard to recommend the right mode for your desired layout.

Quick mode

The easiest and most flexible mode in terms of creating a layout where you can setup custom margins that is not based on the document grid. You can also apply any baseline grid to the document or enter a desired value that will adjust for a perfect fit within the type area. This mode allows you to apply a custom type area grid (the area within the margins) and custom columns and rows.

Modular mode

Synced with Smart mode. Enter your desired grid cell width and height — Grid Calculator finds the closest matching values within the document grid. Allows you to create modules (big blocks) and split into subdivisions (small blocks).

Smart mode

Synced with Modular mode. Great if you already know the number of columns and rows you need for your layout — the type area expands or contracts to fit, think of it like reverse engineering your layout. You can also enter desired margin values and have the closest possible be applied and then pick whatever columns and rows fit.

Frequently asked questions

What versions of InDesign does Grid Calculator PE support?

Grid Calculator PE supports Adobe InDesign CC 2026 and future versions (Mac). When Adobe releases a new version, we update the plug-in to match — your subscription covers all updates at no extra cost.

Does it work on Windows?

Currently Grid Calculator PE is available for macOS only.

Can I use it on more than one computer?

Yes. Your license can be activated on up to 2 computers, but only used on one at a time.

What happens when I cancel my subscription?

Your access continues until the end of the current billing period. After that, the plug-in will stop working. Your presets are stored in Documents/Grid Calculator Publishing Edition and can be used again once plug-in is activated again.

Is there a free demo?

Yes — a 30-day demo is available for download from this page. The demo lets you evaluate all features before purchasing.

How do I install the plug-in?

Download the installer from this product page, close InDesign if it's running, and run the .pkg file. On next launch, Designers Bookshop menu will appear in Adobe InDesign. Activate plug-in; enter all details except license to activate demo or enter license to activate your license.

I upgraded InDesign — do I need to reinstall?

Yes. Each version of InDesign requires its own specific version of the plug-in. After upgrading InDesign, download the latest installer from the product page and run it. Your settings and presets will be preserved.
