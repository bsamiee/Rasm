# [ACROBAT]

Adobe Acrobat Pro reaches automation through Apple events alone. The tool surface below is complete at its contracts: every tool has its input Schema, its output union, its call order, and its save rule now, so later depth fills bodies and adds no tool row and no channel. Acrobat owns no project: the trusted-function file, the action step lists, the Combine presets, and the preference tuples are data beside the server's `acrobat/` module, deployed by the server's own target.

Evidence tags: `[JS]` a `do script` read on 26.002.21901, `[DISK]` a file or folder read, `[PLIST]` `plutil -p` over the user plist, `[AX]` an accessibility read of the menu bar or a dialog, `[IMG]` a window capture, `[SEQU]` the six shipped `.sequ` files, `[CAB]` the shipped lockdown cabinet, `[BIN]` printable strings of `Acrobat.framework/Acrobat`, `[PLUG]` printable strings of a plug-in or framework binary, `[DOC]` an Adobe help page with its update date, `[PREF]` the macOS Preference Reference, `[JSREF]` the Acrobat JavaScript reference. Measurements are 2026-09-11 and 2026-09-14 unless a row names another date.

## [02]-[CHANNEL]

One statement form carries every call. The server writes the AppleScript to stdin of `osascript -` through `ChildProcess.make('osascript', ['-'], {stdin})` with the script as a `Stream`, reads `exitCode`, `stdout`, and `stderr` from the spawned handle concurrently, and classifies the reply.

```applescript
with timeout of <seconds> seconds
tell application id "com.adobe.Acrobat.Pro"
do script "<js>"
end tell
end timeout
```

Interpolation escapes `\` to `\\` and `"` to `\"`, so no shell and no `quoted form of` takes part. The JavaScript body is one immediately invoked function whose value and whose error both leave as JSON on stdout:

```javascript
(function () {
  try {
    return JSON.stringify({ ok: true, value: (function () { <code> })() });
  } catch (e) {
    return JSON.stringify({ ok: false, name: e.name, message: e.message, lineNumber: e.lineNumber });
  }
})()
```

`osascript` prints the `do script` result on stdout at exit 0 and prints `<line>:<column>: <syntax|execution> error: <message> (<code>)` on stderr at exit 1. The classifier reads the phase first, then the code.

| [INDEX] | [REPLY]                                     | [VARIANT]                       | [FIELDS]                     |
| :-----: | :------------------------------------------ | :------------------------------ | :--------------------------- |
|  [01]   | Exit 0, `ok:true`                           | Tool output of the row's `kind` | Decoded through its Schema   |
|  [02]   | Exit 0, `ok:false`                          | `HostThrew` carrying `ScriptThrew{name, message, line}`, or `NotAllowed{method}` when `name` reads `NotAllowedError` | `host`, `rejection`          |
|  [03]   | `syntax error` at any code                  | `ScriptNotCompiled`             | `host`, `code`, `line`       |
|  [04]   | `execution error` −1743                     | `AutomationDenied`              | `host`                       |
|  [05]   | `execution error` −1712                     | `HostUnresponsive`              | `host`, `code`               |
|  [06]   | `execution error` −600                      | `HostNotRunning`                | `host`                       |

Measured shapes behind the table: −1743 is "the target of the AppleEvent does not allow this sender to execute this event"; −1712 is `errAETimeout`, and the host finishes the script and answers the next call; −1708 is an unknown event, proven against Acrobat with `«event miscNOPE» "x"`; a bad bundle id compiles to `syntax error … (-1728)` before any event is sent, which the `as const` bundle id makes unreachable. A `syntax error` is a defect in the template, never a host state.

Acrobat error names the `ok:false` branch carries: `NotAllowedError`, `GeneralError`, `RaiseError`, `DeadObjectError`, `HelpError`, `UnsupportedValueError`, `TypeError`. Recovery reads `name`, never the rendered text. Measured shapes (2026-09-15): `app.getPath("user", "help")` answers `GeneralError: Operation failed.` because the folder is absent, and the same call answers the path once the folder exists; `doc.saveAs({cPath, cConvID: undefined})` and `cConvID: "com.adobe.acrobat.pdf"` (off `app.fromPDFConverters`) answer `UnsupportedValueError: Value is unsupported. ===> Parameter cConvID.`; `app.execMenuItem(cName, undefined)` answers `TypeError: Invalid argument type.`.

Paths Acrobat returns (`doc.path`, `app.getPath`) are device-independent, `/Macintosh HD/private/tmp/…/scratch-a.pdf`, while every `cPath` input takes the POSIX form; the server passes POSIX paths in and strips the `/Macintosh HD` prefix on the way out. A command that opens a modal dialog holds the reply until the dialog closes, so the call ends in −1712 (`AccCheck:DoCheck` with `Accessibility Checker Options` open, 20 s timeout); a command that runs after the script returns answers first (`Adobe:MakeAccessible` returns with `dirty false`, the document reads `dirty true` on the next call).

The channel launches the host: `tell application id` starts a target that is not running when a statement needs a reply, so the process assertion precedes every call and `running of application id` reads state without launching.

Two parameter shapes are measured, and the listing below carries their fix: `saveAs` with `cConvID` absent must omit the key, since `{cPath, cConvID: undefined}` throws `UnsupportedValueError`, and `execMenuItem` with `oDoc` absent must call the one-argument form, since `app.execMenuItem(cName, undefined)` throws `TypeError`.

```javascript
// Privileged bridge of the acrobat_* tools; no menu item, no button, no UI
console.println("rasm-trusted loaded " + app.viewerVersion);
var rasmTrusted = {
  getPath: app.trustedFunction(function (cCategory, cFolder) {
    app.beginPriv();
    var cPath = app.getPath(cCategory, cFolder);
    app.endPriv();
    return cPath;
  }),
  saveAs: app.trustedFunction(function (oDoc, cPath, cConvID) {
    app.beginPriv();
    oDoc.saveAs(cConvID === undefined ? { cPath: cPath } : { cPath: cPath, cConvID: cConvID });
    app.endPriv();
    return cPath;
  }),
  execMenuItem: app.trustedFunction(function (cName, oDoc) {
    app.beginPriv();
    if (oDoc === undefined) app.execMenuItem(cName); else app.execMenuItem(cName, oDoc);
    app.endPriv();
    return cName;
  }),
  newDoc: app.trustedFunction(function (nWidth, nHeight) {
    app.beginPriv();
    var oDoc = app.newDoc(nWidth, nHeight);
    app.endPriv();
    return oDoc;
  }),
  insertPages: app.trustedFunction(function (oDoc, nPage, cPath, nStart, nEnd) {
    app.beginPriv();
    oDoc.insertPages({ nPage: nPage, cPath: cPath, nStart: nStart, nEnd: nEnd });
    app.endPriv();
    return oDoc.numPages;
  })
};
```
