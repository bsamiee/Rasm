# [DELIVERY]

Prepare the requested document or publication for its intended reader and deliverables. Preserve editable sources and native relationships while resolving output defects.

## [01]-[REQUIREMENTS]

Establish output format, page scope, reader, color requirements, accessibility, and source-file delivery. Distinguish print pages from reader spreads and static presentation artwork from interactive behavior. For a book, retain native membership and ordering throughout combined output.

Choose a native preset when its actual settings match requirements. Resolve differing requirements before changing document profiles, export conversion, bleed, font embedding, or image sampling.

## [02]-[SOURCE]

Resolve missing or modified sources through their actual links. Preserve local appearance and content according to linked-content policy. Correct overset, unintended overrides, broken references, and stale generated text at their native owners.

Run preflight under the intended profile and scope. Read complete rule results and configured thresholds. Associate reported problems with native objects before editing; report hierarchy and page labels do not establish object identity.

For accessible output, align semantic styles, native lists and tables, reading order, alternative text, and export tagging. For interactive output, retain navigation targets, field order, state membership, event triggers, and media sources required by the reader.

## [03]-[OUTPUT]

Inspect composed pages at a scale that exposes type and image detail. Evaluate beginning, middle, ending, and demanding layouts from the actual page sequence. Correct repeated defects through shared definitions.

Export through the native owner for the selected format and await native completion. Inspect resulting files for the properties document appearance cannot prove: page extent, tags, font embedding, reading order, navigation, and interactive playback in the intended reader.

When source-file delivery is requested, package required assets and report unavailable sources or fonts excluded by licensing and activation rules. Packaging cannot recover a missing source.

## [04]-[HANDOFF]

Return completed deliverables and native completion outcomes. Identify unresolved output-affecting findings with their affected scope. State reader or production requirements that remain necessary to use the result.
