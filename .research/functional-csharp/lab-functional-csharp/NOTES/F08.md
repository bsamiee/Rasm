## Members verified

- `Seq<A>.Map(Func<A, B>)`: instance, returns `Seq<B>`.
- `Option<A>.Map(Func<A, B>)`: instance, returns `Option<B>`; a method group (`Map(CalculateRiskProfile)`) binds.
- `Functor<F>`: trait with `static abstract K<F, B> Map<A, B>(Func<A, B> f, K<F, A> ma)`; a generic function over `F : Functor<F>` calls `values.Map(f)` through `FunctorExtensions`.
- `Lengths(Some("ab"))` and `Lengths(Seq("a", "bb"))` infer `F` as `Option` and `Seq` from the argument's `K<F, string>` interface, no explicit type arguments; `.As()` recovers `Option<int>` and `Seq<int>`.
- `Option<A>.Iter(Action<A>) : Unit`; `Iter(Console.WriteLine)` binds the method group to `Action<string>`.
- `Seq<A>.Iter(Action<A>) : Unit` from `FoldableExtensions`.
- `Fin<A>.Iter(Action<A>) : Unit` and `Fin<A>.IfSucc(Action<A>) : Unit`.
- `Option<A>.Do(Action<A>) : Option<A>`; `Seq<A>.Do(Action<A>) : Seq<A>`.
- `IO.lift(Action) : IO<Unit>` as an observer step inside an `IO` LINQ chain; the lambda captures the bound value and is not `static`.
- `Option<A>.Bind(Func<A, Option<B>>)`; `parseInt(input).Bind(static value => Age.From(value).ToOption())` with `Age.From : int -> Fin<Age>`.
- `Seq<A>.Bind(Func<A, Seq<B>>)` flattens.
- `Pure<A>` converts implicitly to `Option<A>`, `Fin<A>`, and `IO<A>`.
- `Applicative<F>.Pure<A>(A) : K<F, A>` called as `F.Pure(value)` under `where F : Applicative<F>`; `Lift<Seq, int>(1).As() == Seq(1)`.
- `MonadLaw<Option>.validate() : Validation<Error, Unit>` succeeds.
- `Option<A>.Filter(Func<A, bool>)`.
- `Option<A>.ToSeq() : Seq<A>`.
- `Seq<A>.Choose(Func<A, Option<B>>) : Seq<B>` from `SeqExtensions`.
- `Seq<Option<A>>.Somes() : Seq<A>` from `OptionExtensions`.
- `Seq<A>.Fold(S, Func<S, A, S>)` from `FoldableExtensions`.
- `Seq<A>.Rev()` from `SeqExtensions`.
- `toSeq(Range(1, 100))`; `Range(int from, int count, int step = 1)` takes a count, so `Range(1, 100)` is 1 to 100.
- `OptionT.lift<IO, A>(Option<A>) : OptionT<IO, A>`; `Run() : K<IO, Option<A>>`, then `.As().RunSafe() : Fin<Option<A>>`.
- `Fin<Option<Age>> == Pure(Some(Age.Create(30)))` compiles and holds.

## Corrections to the plan and the API document

- CORRECTION (plan): `Fin<A>` has no `Filter` and no `Where`. `sigs/Fin_1.txt`, `FinExtensions.txt`, and `FinGuardExtensions.txt` list neither. The doc scopes `Filter` to `Option<A>` and `Seq<A>` and states that `Fin<A>` has no `Filter`; `guard` in LINQ is the `Fin` form.
- CORRECTION (plan): `Pure(x)` does not convert into `Seq<A>`. `Seq<A>` declares one implicit operator, from `SeqEmpty`. The `LanguageExt.Seq` module implements `Applicative<Seq>.Pure` as an explicit interface member, so `LanguageExt.Seq.Pure(1)` fails with CS0117. The trait call `F.Pure(value)` under `F : Applicative<F>` is the general form, and `Seq(value)` is the concrete one.
- CORRECTION (API document): `Seq<int>.Average()` fails with CS0121, ambiguous between `FoldableExtensions.Average<T, A>(K<T, A>)` and `Enumerable.Average(IEnumerable<int>)`. `Seq<A>` implements both `K<Seq, A>` and `IEnumerable<A>`, so the instance-style call cannot pick one. The doc aggregates with `Fold`.
- CORRECTION (extends the `List.unfold` ruling): `Seq<Pet>.Empty` in expression context fails with CS0119 because the simple name `Seq` binds to `Prelude.Seq<A>()`. `Seq<Pet>()` builds the empty sequence. In a type-argument position (`Lift<Seq, int>`, `K<Seq, A>`) the simple name resolves to the type.
- The `Seq.txt` signature file in DECOMP holds the `Seq<A>` struct, not the `LanguageExt.Seq` module; `ilspycmd -t 'LanguageExt.Seq'` shows the module.
