   **Claim** "the discard arm gives an unknown event an explicit outcome"
   **Evidence** The discard arm in the shown `Apply` is
   `_ => throw new ArgumentOutOfRangeException(nameof(evt)),`. A throw is not an outcome, and the
   corpus reserves exceptions for defects. `NOTES/F14.md` states the intent: "an unknown event type
   is a defect, not an expected error".
   **Correction** Replace the clause with: "and the discard arm treats an unknown event as a defect
   and throws."
