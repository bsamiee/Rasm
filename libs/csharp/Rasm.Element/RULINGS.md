## [02]-[SHAPE]

- Seam vocabulary stays provider-blind — no GeometryGym, host, or app-platform type enters any `Rasm.Element` surface; every ingest enrichment lands as neutral graph content a peer decodes without the producer's assembly, and a new ingest feature proposing a provider payload column for convenience is the recurring move this row rejects — one provider type on the seam couples every projector and consumer to that provider's assembly.
- `AppearanceSummary` is FROZEN at its seven-value preimage and its eight-parameter `Of(…, Op key) -> Fin<AppearanceSummary>` arity — a richer appearance fact (a baked texture-set key, an environment binding, a UV transform, a measured refractive index) hangs BEHIND the `AppearanceKey` on its producer's own wire, because an eighth column re-keys every stored `Node.Appearance` and forks the `Rasm.Bim` surface-style dedup key in the same edit while both peers mint through this one factory; the recurring move reads the record as an open PBR bag and adds the column at whichever peer needed it, which is invisible until two runtimes disagree about one surface's id, and re-litigation opens only under a coordinated re-key of every persisted appearance node.
- Float-bearing members on this branch never take `[PrecisionEquality]` — the generator omits precision members from `GetHashCode` entirely, so a payload distinguished only by tolerance-compared scalars collapses to one hash bucket. Reopens only on a float-bearing member whose tolerance no canonical projection already owns.
- Every double the graph carries is tolerance-owned elsewhere: a `MeasureValue` quantized to `Header.Tolerance` by the canonical projection, where a second tolerance forks the cross-runtime parity corpus, or an `AppearanceSummary` channel preimage to a frozen `AppearanceKey`, where tolerance-equality rules two nodes equal whose content keys differ.
- String members the `CanonicalWriter` writes verbatim declare `[StringEquality(StringComparison.Ordinal)]` rather than inheriting the default, so equality and content identity cannot fork on a comparer edit.
- Imported material `Pset` rows land in a neutral `Properties/property#PROPERTY_BAG` node keyed by the foreign set name under `PropertySource.Import`, never as Option-widened columns on the FULL-VECTOR typed `MaterialPropertySet` cases — a partial foreign set folded onto a case fabricates every undeclared column, and the recurring move reads that family as an open bag because a foreign set name matches a case. Reopens where a published template proves one foreign `Pset` TOTAL against one case.
- Foreign provider sentinels never become seam column types — GeometryGym's `int.MinValue` unset priority, a `NaN` extent, a defaulted enum retire to `Option<T>` at the projector read that first sees them, and a three-state foreign logical takes the one `Option<bool>` encoding `PropertyValue.Logical` ratifies, never a second per-domain vocabulary; the recurring move mirrors the provider's field type onto the seam row for fidelity, carrying the sentinel into the hash and the wire.
