#### Step model

`{name, description, groups:[{label, steps:[step]}]}` with `step` one of `{op:'command', name, prompt:boolean, items?:[{name, type, value}]}`, `{op:'instruction', text}`, `{op:'separator'}`, `{op:'preflight', profile, fixups:boolean}`, `{op:'save'}`, `{op:'execJs', code}`. Serialization: `command` → row 04 verbatim; `preflight` → `CALS:Preflight` with `PROFILE_NAME` the profile name, `DICTKEY` and `FINGERPRINT` read from `Default Preflight.kfp` ([04.1] row 06; the `.kfp` is greppable text: `rg -a -o 'P_[0-9]+_[A-Za-z0-9]+|P[0-9a-f]{31}' Actions.kfp` lists `P_8_ConverttoPDFA1b`, `Pae7f2ad658ba0fef73e78e65d4e02c22` `[DISK]`), `OMIT_FIXUPS` the negation of `fixups`, report rows `0`; `save` → `WorkflowPlaybackSaveFiles` with `DocSaveDestType WorkflowPlaybackSaveAs`; `execJs` → the form of [07] row 22. Server run (`acrobat_run_action`, `acrobat_batch`): `command` without `items` → `rasmTrusted.execMenuItem(name, doc)` ([04.5] row 01); `command` with `items` → `StepNeedsWizard{name}` (execMenuItem carries no items, the Wizard does); `preflight` → `doc.preflight(Preflight.getProfileByName(profile), !fixups)` ([04.2]); `save` → `rasmTrusted.saveAs(doc, output)`; `execJs` → the code inside the tool's IIFE; `instruction` and `separator` → skipped. `acrobat_run_action` output: `{kind:'action', ran:[stepIndex], perFile:[{path, ok, reason?}]}`, `reason` one of `StepNeedsWizard{name}`, `OpenFailed{path}`, `SaveRefused{path}`, `PreflightThrew{profile, message}`.
