Doc is 295 lines. All eight `csharp` blocks match `F22/*.cs` verbatim modulo the `namespace Lab.F22;` line (byte-compared). No cross-file reference, no banned token, no `IO<Fin<`/`IO<Option<` text, no hedge, no bare `Eff<X>`, no sentence at or over 25 words.

1. **Location** line 50 (Exits prose).
   **Claim** "`Run` and `RunAsync` throw an `ErrorException` on failure and belong to `Main`."
   **Evidence** `Expected.Throw<R>() => throw ToErrorException()`, but `Exceptional.Throw<R>()` is `if (Value != null) return Value.Rethrow<R>();` (ilspycmd `LanguageExt.Common.Exceptional`), so a captured exception is rethrown as itself. Cancellation leaves `RunAsync` as `ValueTask.FromCanceled` (`IO_1.cs` RunAsync top), which the same paragraph later admits.
   **Correction** "`Run` and `RunAsync` throw the error as an exception and belong to `Main`."

2. **Location** line 151 (Recursion prose).
   **Claim** "`RepeatUntil` and `RepeatWhile` poll one effect until its value satisfies the predicate."
   **Evidence** `public IO<A> RepeatWhile(Func<A, bool> predicate) => RepeatUntil(Prelude.not(predicate));` (`IO_1.cs:554`). Probe run: `IO.lift(() => n.Swap(x => x + 1)).RepeatWhile(x => x < 3).RunSafe()` returned `Succ(3)`, so it stopped when the predicate turned false.
   **Correction** "`RepeatUntil` polls one effect until its value satisfies the predicate, and `RepeatWhile` polls while the value satisfies it."

3. **Location** line 50 clause "`Try()` returns `FinT<IO, A>`, and its `runFin` keeps the `Fin` inside the effect." and line 56 `public static Fin<int> Inside => Construction.Failed.Try().runFin.As().Run();`
   **Claim** as quoted.
   **Evidence** `public record FinT<M, A>(K<M, Fin<A>> runFin)` (`sigs/FinT.txt:13`), so `runFin.As()` is an `IO<Fin<int>>` value. The global ruling gives one host exit for a bare effect (`RunSafe() : Fin<A>`) and bans the nested shape; the file already carries two justified exits (`RunSafe`, and `Try.lift(io.Run).Run()` for the tail-call and cancellation carve-outs). This third exit has no stated need and is the only place the banned nesting is constructed.
   **Correction** delete the `Inside` member from the block and the lab file, and shorten the sentence to "`Try.lift(io.Run).Run()` captures the thrown error and returns the original `Expected`."

4. **Location** line 173 (Schedules prose).
   **Claim** "`Retry(Schedule)` reruns a failed effect and `Repeat(Schedule)` reruns a successful one."
   **Evidence** `IOFail<A>.RetryUntil(Schedule, Func<Error, bool>) => this` (ilspycmd `LanguageExt.DSL.IOFail\`1`). Probe run: `IO.fail<int>(new Unavailable()).Retry(Schedule.recurs(3)).RunSafe()` returned `Fail` with no rerun, while the deferred form retried three times. This is the same node rule the file states for `Finally` at line 73.
   **Correction** "`Retry(Schedule)` reruns a deferred effect that failed and `Repeat(Schedule)` reruns a successful one."

5. **Location** line 229 (Streams prose).

   **Correction** "`Source<A>` is a stream of values."
