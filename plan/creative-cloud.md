# [CREATIVE_CLOUD]

One application, `apps/creative-cloud`, holds one stdio MCP server, `creative-cloud`, whose typed tools drive Illustrator, Photoshop, InDesign, and Acrobat, and the configuration pass that each host takes through those tools. An orchestrator drives the units of [06] in order and every builder reads this file first, then the design file sections its unit names.

## [01]-[INTENT]

Tool tables publish per host as `<host>_<verb>` rows beside the cross-host `health`. Agents call tools; no panel, dialog, menu item, shortcut, or scripts-folder copy is a unit of work, and each application pass drives the GUI through computer-use and the window-list reader where no DOM property exists, each step naming its channel. Agents reach the host tables of this server and the official Illustrator MCP server, whose `.mcp.json` row `illustrator` stays and whose 47 tools no `illustrator_*` tool duplicates (`plan/research/README.md` [04]).

Every product below is read in full, and its replacement holds every mode, option, and output the product exposes, corrects the defects the reading found, and states per product which tool holds each function (`plan/design/indesign.md` [10], `plan/design/typography.md` [02], `plan/design/illustrator.md` [06]).

## [07]-[PROTOCOL]

| [INDEX] | [RULE]                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| :-----: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|  [01]   | One orchestrator dispatches one Fable builder per unit and writes no code itself                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|  [02]   | Builders read this file, the design file sections their unit names, the research READMEs those name, `CLAUDE.md`, and the newest official documentation of every package they call before their first file                                                                                                                                                                                                                                                                                                                                                                                       |
|  [03]   | Builders guess no API, DOM member, config key, or host fact: they read the documentation, the installed package's declarations, the readable reference implementation, or the running host, and write what they read                                                                                                                                                                                                                                                                                                                                                                        |
