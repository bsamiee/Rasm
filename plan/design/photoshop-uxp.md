# [PHOTOSHOP_UXP]

Transport-only UXP plugin for Photoshop Beta 27.11 driven by an MCP server over a local WebSocket. Every row names its source: `machine` is a read-only probe on this Mac on 2026-09-11, `adobe` is a page of developer.adobe.com or helpx.adobe.com fetched on 2026-09-11 with its URL in [12], `types` is `@adobe-uxp-types/photoshop@0.1.8` or `@adobe-uxp-types/uxp@0.1.4` read from unpkg on 2026-09-11, `sidekick` is the pretty-printed InDesign plugin `8ebe7f95_1.0.22`, `forum` is a dated Adobe forum post. A claim with no source of those kinds is a row in [10] and nowhere else. The listener, the job model, the error vocabulary, and the tool rows are `architecture.md` [03] to [06]; this file holds the host facts they rest on.
